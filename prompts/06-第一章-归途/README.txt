================================================================================
    第一章·归途 — 场景提示词总览 (V4.5 · 混合媒材最终版)
================================================================================

【说明】
本文件夹包含《灰山》第一章「归途」的全部场景视觉提示词。
每个文件对应一个场景，按探索顺序排列。

所有提示词统一使用混合媒材最终风格：
  - 水彩渲染（watercolor wash）— 背景气氛与雾气
  - 蘸水笔墨线（dip pen ink lines）— 建筑细节与轮廓
  - 炭笔阴影（charcoal shading）— 深层阴影与粉末纹理
  - 粗纹水彩纸基底（rough watercolor paper）— 统一手工质感

风格继承关系：
  00-风格定义/主风格基准.txt  →  全局画风标签
  00-风格定义/黑白恐怖风格.txt  →  恐怖氛围叠加
  00-风格定义/negative_prompt.txt  →  通用负面提示词

【使用方式】
每个场景的 Base Prompt 可独立使用，也可叠加 00-风格定义 中的标签。
