# 灰山

> 克苏鲁风格视觉小说 · Ren'Py 引擎

---

汤姆·卡特，一位波士顿风景画家，在意大利五渔村邂逅了热那亚姑娘艾琳娜。她随他远渡重洋，在波士顿市政厅结婚。两人的生活像一幅明亮的水彩——直到 1931 年，艾琳娜确诊肺结核。

韦斯特医生推荐了灰山疗养院。海拔九百米，南坡，新鲜空气疗法。汤姆第一次独自探路时，山脚的石头教堂前，一位爱尔兰老神父对他说："这座山，有时候会让人觉得喘不过气。不是海拔的问题。"

艾琳娜入院后起初好转，随后病情急转直下，死于心脏骤停。汤姆下山回到波士顿，却发现世界开始松动：他画的风景里多出了从未落笔的东西——雪地中的脚印、远处的人影、山顶裂开的缝隙。他分不清是白天的山进入了夜晚的梦，还是梦中的山在白昼等着他。

他被诊断为精神分裂，关进精神病院。一个暴风雪夜，他逃了出来，朝灰山走去。

山之下沉睡着某种东西——不是神，不是魔，是一种在"生命"这个词出现之前就已存在的、具有意识的物质。石灰岩的缝隙是它呼吸的通道。而那座山，只是它露在地表之上的最末端一根骨节。

> 终点不止一个。但所有路都通向同一座山。

## 技术架构

| 项 | 内容 |
|---|---|
| **引擎** | Ren'Py 8.x（Python 3） |
| **UI 主题** | Black & White Horror UI，自制暗色单色风格 |
| **字体** | IMFellDWPica（衬线）+ Literata（正文） |
| **存档方案** | `default` 声明存档变量 + `flags` 字典管理旗标 |
| **平台目标** | Windows / macOS / Linux |

### 工程结构

```
game/
├── script.rpy              # 主脚本（当前为占位 demo）
├── scripts/                # 章节脚本（待填充）
│   ├── definitions.rpy     #   集中定义：角色 / 图像 / 音频
│   ├── ch00_prologue.rpy   #   序章
│   ├── ch01_diagnosis.rpy  #   第一章 · 会诊室
│   ├── ch02_ascension.rpy  #   第二章 · 登灰山
│   ├── ch03_sanatorium.rpy #   第三章 · 疗养院
│   ├── ch04_collapse.rpy   #   第四章 · 崩塌
│   └── ch05_escape.rpy     #   第五章 · 出逃 + 结局分支
├── screens.rpy             # UI 界面（菜单/对话框/存档/设置等）
├── options.rpy             # 引擎配置（分辨率/存档路径/转场等）
├── gui.rpy                 # GUI 样式变量
├── custom_config.rpy       # 自定义主题（黑白恐怖风格覆盖）
├── gui/                    # UI 素材（按钮/滚动条/滑块/叠加层等 PNG）
│   └── phone/              #   移动端适配素材
├── images/                 # 游戏图像（场景/角色立绘/CG）
├── fonts/                  # Web 字体文件（IMFellDWPica + Literata）
├── saves/                  # 存档目录
└── tl/                     # 翻译目录
```

### 设计文档

```
docs/
├── settings/               # 核心设定（世界观/角色/时间线/地图/物品）
├── storys/                 # 章节分镜（ch01 ~ ch17）
├── scripts/                # 脚本成型稿
├── requirements/           # 需求文档
└── twine/                  # Twine 原型
```

### 美术管线

```
prompts/                    # NovelAI 生图提示词
├── 00-通用规范/            #   风格一致性约束
├── 01-角色/                #   角色立绘
├── 02-背景场景/            #   场景图
├── 03-事件CG/              #   关键事件 CG
├── 04-UI元素/              #   界面素材
└── 05-氛围特效/            #   滤镜/噪点/光效等

Images/                     # AI 生成成品图（分类存放）
```

### 分支系统

5 个结局，通过 `flags` 字典驱动：

| 结局 | 关键旗标 |
|---|---|
| A · 记忆消失 | 带艾琳娜下山前 |
| B · 自杀 | — |
| C · 精神病院 | 未出逃 |
| D · 山洞死亡 | 出逃 + 未获救 |
| E · 山洞生还 | 出逃 + 获救 |
