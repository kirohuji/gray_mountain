# 山中教堂

## 基本信息

| 项目 | 内容 |
|------|------|
| 名称 | 圣某某堂（St. —— 名称待定） |
| 位置 | 灰山东南山脚，海拔约 400 米，进山必经之路上 |
| 建筑年代 | 约 150 年历史（≈ 1780 年代） |
| 材质 | 灰色石灰岩——与山体同色同源，像从山里长出来的 |
| 规模 | 小型石头教堂，钟楼 + 礼拜堂 + 神父住所 |
| 现任神父 | 迈克尔·奥布莱恩（60多岁，爱尔兰移民后代） |
| 前任神父 | 老莫纳汉（1920 年去世） |
| 游戏地位 | 汤姆的精神庇护所——唯一可以"说出真相"的地方 |

## 建筑风格细节

### 外部

| 元素 | 描述 |
|------|------|
| 墙体 | 灰色石灰岩，粗凿，与山体同色 |
| 屋顶 | 石板瓦，深灰色，边缘有青苔 |
| 钟楼 | 矮小，仅比屋顶高出一层，铜钟老旧 |
| 木门 | 厚重橡木门，铁制铰链与门环 |
| 周围 | 几棵老橡树，一小片墓园（疗养院去世患者的部分埋葬地） |
| 位置感 | 嵌在山脚——不是"建在"山脚，是"属于"山脚 |

### 内部·礼拜堂

| 元素 | 描述 |
|------|------|
| 空间 | 小型，约容纳 30 人 |
| 长椅 | 深色橡木，6 排，老旧但维护良好 |
| 祭坛 | 简朴，石制，没有华丽装饰 |
| 光线 | 仅靠两扇窄窗——即使在白天也很昏暗 |
| 烛台 | 铁制，蜡烛常年燃烧——为疗养院的患者祈祷 |
| 气氛 | 不是"神圣"，是"安静"——一个容纳悲伤的地方 |

### 神父住所

| 房间 | 描述 |
|------|------|
| 书房 | 书桌、旧书、壁炉、两把旧扶手椅——汤姆与神父对谈之处 |
| 卧室 | 简朴，铁架床，墙上挂十字架 |
| 小厨房 | 煤油炉、茶壶——神父给汤姆倒茶的地方 |
