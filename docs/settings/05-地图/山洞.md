# 山洞

## 基本信息

| 项目 | 内容 |
|------|------|
| 位置 | 灰山北侧山腰，隐蔽在陡坡松林间 |
| 类型 | 天然石灰岩溶洞，内部有地下河支流 |
| 规模 | 洞口狭窄，内部逐渐扩大——主洞室约 20m² |
| 游戏地位 | 汤姆的最终目的地——结局 4 和结局 5 的发生地 |

## 洞内特征

| 元素 | 描述 |
|------|------|
| 入口 | 窄缝，被松枝半遮——像是故意隐藏 |
| 通道 | 最初几米需侧身通过，随后豁然开朗 |
| 主洞室 | 天然穹顶，石灰岩钟乳石，地下河在洞底流过 |
| 墙壁符号 | 刻痕古老——不是文字，更像是某种"呼吸的图示" |
| 光 | 无自然光——仅有洞口透进的微光或汤姆携带的火柴 |
| 温度 | 恒温——比洞外暖（暴风雪之夜，这是致命的诱惑） |
| 声音 | 地下河的水声 + 岩石深处传来的低频嗡鸣——每分钟六次 |

## 剧情关联

| 结局 | 内容 |
|------|------|
| 结局 4（死亡） | 汤姆在暴风雪中到达山洞，食物耗尽，火柴湿了。他在洞中产生了与艾琳娜重逢的幻觉——然后永远闭上了眼睛。搜救队在三天后只找到了画具和外套。 |
| 结局 5（幸存） | 汤姆在洞中找到艾琳娜（或是她的某种"形态"）——两人坚持到救援队到达。 |

## 视觉参考

- 洞口：松林间一道不起眼的石灰岩裂隙
- 通道：窄、湿、黑暗，手触岩壁感到极细粉末
- 主洞室：幽暗的石灰岩穹顶，钟乳石如牙齿倒挂，地下河泛着磷光般的灰白
