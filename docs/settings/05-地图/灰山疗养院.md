# 灰山疗养院

## 基本信息

| 项目 | 内容 |
|------|------|
| 名称 | 灰山疗养院（Ash Mountain Sanatorium） |
| 位置 | 灰山南坡山腰，海拔约 900 米 |
| 建立时间 | 1915 年，由马萨诸塞州公共卫生部资助 |
| 初代建立者 | 伊莱沙·莫恩（Elijah Morn）——1920 年发疯，死于精神病院 |
| 现任院长 | 亨利·韦斯特医生（50多岁） |
| 规模 | 三栋主楼，约 120 张床位 |
| 建筑材质 | 当地石灰岩——与山体同源 |
| 到达方式 | 从最近小镇开车两小时，最后五公里碎石路 |

## 病房楼详解（核心建筑）

### 建筑特征

| 特征 | 描述 |
|------|------|
| 楼层 | 三层，层高约 3.5m |
| 外墙 | 灰白色石灰岩，与山体同色同源 |
| 窗户 | 巨大，从天花板延伸到腰部——保证最大通风 |
| 阳台 | 南侧和西侧宽大阳台——核心治疗区域 |
| 地板 | 深色木质，略有倾斜（便于阳台排水） |
| 走廊 | 长而直，两侧病房门对称排列，灯光昏暗 |

### 床位等级（剧情重要）

| 位置 | 空气质量 | 治疗定位 | 异常风险 |
|------|---------|---------|---------|
| 阳台床位 | 最佳——直接接触山间空气 | "抢手位置" | ★★★ 最危险 |
| 靠窗床位 | 良好——开窗通风 | "治疗质量高" | ★★☆ |
| 靠墙床位 | 较差——空气来自墙体渗入 | "给病情较轻的人" | ★☆☆ 相对安全 |
| 私人病房 | 独立通风 | 给病情最重的患者 | ★★★ |

> **核心隐藏设定**：靠里床位（空气来自石灰岩墙体渗入）反而比靠窗床位更危险——因为石灰岩是多孔结构，是"它"呼吸的通道。墙体渗入的空气含有更高浓度的灰白色粉末。

### 建筑质感

| 元素 | 描述 |
|------|------|
| 墙壁 | 灰白石灰岩，触感冰冷，内墙刷白垩粉 |
| 地面 | 深色木地板，走廊铺长条地毯（消音），阳台略有倾斜 |
| 门窗 | 白色木框大窗，黄铜把手，门厚重 |
| 灯光 | 走廊壁灯昏暗，病房白天靠自然光 |
| 供暖 | 老式暖气片，冬季咝咝作响 |

### 声音景观

| 声音 | 来源 |
|------|------|
| 远处咳嗽声 | 病房——日夜不停 |
| 风声/耳鸣般的低鸣 | 石灰岩墙体——不是风 |
| 暖气片咝咝声 | 供暖管道 |
| 韦斯特医生的脚步声 | 查房——白大褂窸窣 |
| 阳台上的静默 | 最响亮的声音——患者躺着不说话 |

### 气味

| 气味 | 来源 |
|------|------|
| 消毒剂（石炭酸） | 日常清洁 |
| 松树与湿石灰 | 山间空气混入 |
| 浆洗床单的碱味 | 洗衣房 |
| 旧木头 | 地板与家具 |
