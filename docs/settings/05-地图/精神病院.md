# 州立精神病院

## 基本信息

| 项目 | 内容 |
|------|------|
| 名称 | 马萨诸塞州立精神病院（名称待定/虚构） |
| 位置 | 波士顿近郊 |
| 收治对象 | 精神分裂症、严重抑郁、幻觉障碍等重症患者 |

| 出现章节 | 第三章·崩塌 → 第四章·出逃 |

## 汤姆的病房

| 项目 | 内容 |
|------|------|
| 楼层 | L3 · 重症封闭区，走廊尽头 |
| 类型 | 单人隔离病房 |
| 布局 | 铁架床（固定在地面）、小桌、一把椅子、带铁栏的窗户 |
| 特别规定 | 门从外面上锁，夜间每两小时巡查一次 |
| 汤姆的私人物品 | 被没收——只留下一颗口袋里的石子（他自己都不知道什么时候放的） |

## 风格细节

### 建筑质感

| 元素 | 描述 |
|------|------|
| 外墙 | 红砖，哥特复兴风格，外观像学校或修道院——故意不显压抑 |
| 走廊 | 长而直，油毡地面，日光灯嗡嗡作响 |
| 病房 | 白色墙壁，铁架床，极简——不提供任何可能的自残工具 |
| 气味 | 消毒剂、药味、旧油漆、无数人身上淡淡的汗味 |
| 声音 | 日光灯嗡鸣、远处的门锁声、偶尔的哭喊或自言自语 |

| 04:00 | 汤姆盯着窗户——等待不可能出现的雪 |

## 隐藏设定

| 设定 | 说明 |
|------|------|
| 地基 | 建筑的石灰岩地基——与灰山同一种石材 |
