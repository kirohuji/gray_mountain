# 山顶裂缝

## 基本信息

| 项目 | 内容 |
|------|------|
| 位置 | 灰山峰顶，海拔约 1400 米，永久性倒扣碗状乌云正下方 |
| 外观 | 一道约 10 米长的裂缝，宽度不足以让人掉进去 |
| 真实性质 | 不是地质现象——是"沉睡者"最末端骨节上的一道裂痕 |
| 游戏地位 | 异常可见源头——汤姆写生时发现，后续章节的关键意象 |

## 异常表现

| 现象 | 描述 |
|------|------|
| 灰白色粉末 | 从裂缝中持续逸出，细得像石粉，滑腻——与公寓和疗养院中的粉末同源 |
| 温度异常 | 裂缝边缘比周围岩石更冷——即使在夏天 |
| 声音 | 贴近裂缝听——不是风声。是低频嗡鸣，每分钟六次 |
| 视觉扭曲 | 长时间注视裂缝——边缘开始"蠕动"，不是视觉疲劳 |

## 视觉参考

- 灰白裸岩峰顶，乌云压在头顶几米处
- 裂缝像一道被撕开的伤口，边缘不规则
- 细尘从裂缝中缓缓升腾，融入上方乌云
- 整体色调：灰白、铅灰、病态的青白
