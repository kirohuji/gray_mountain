## 动线逻辑

### 入口 - 玄关 (1)

- 一进门就是狭窄空间（典型波士顿老公寓）
- 放置：衣帽架（coat rack）、穿衣镜（full-length mirror）、雨伞桶（umbrella stand）、鞋柜、电话答录机
- 小地毯覆盖深色木地板
- 角色定位：**安全区 / 初始点**——汤姆从外界回到"家"的过渡空间

### 走廊 (4)

- 窄长的走廊连接所有私密空间
- 左侧通向浴室，右侧通向卧室
- 卧室门在此处——但锁住（关键剧情推进点）
- 向前通往画室（左）、厨房（右）、客厅（正前方）

### 公共区 - 客厅 (6)

- 公寓核心区，连通所有主要空间
- 落地窗连接阳台（光源）
- 放置：老式绒面沙发、茶几、书架、木质收音机
- 角色定位：**主交互区**——玩家将在此触发关键电话事件

### 左右分区

- **左侧：画室 (5)**——汤姆的工作空间，体现角色个性与艺术背景
- **右侧：厨房 (2)**——小而封闭，生活感的来源

### 浴室 (3)

- 靠近入口/走廊左侧
- 符合老建筑管道布局（真实感）
- 高天花板，白色瓷砖，旧管道偶尔发出闷响

### 卧室（不可进入）

- 位于走廊右侧
- 门锁住——第一章的关键悬念点
- 角色定位：**关键推进点**——门不是为汤姆关的，"是为了让她从里面打开的"

### 阳台 (7)

- 通过客厅落地窗进入
- 铸铁栏杆，可见街道景观
- 角色定位：**氛围 / 夜晚事件**——灰白色粉末首次在户外出现

## 1930s Boston 风格细节

### 建筑结构

| 元素 | 描述 |
|------|------|
| 建筑类型 | Brownstone 窄长型公寓 |
| 地板 | 深色木地板，老旧，踩上去有细微的吱嘎声 |
| 天花板 | 高（约 3.2–3.5m），但灯光昏暗 |
| 门窗 | 厚重木门，黄铜把手，老式锁芯 |
| 管道 | 老建筑铁管，浴室与厨房按管道集中布局 |

### 各房间视觉参考

| 房间 | 关键物品 | 风格 |
|------|---------|------|
| 玄关 | 衣帽架、雨伞桶、小地毯、穿衣镜、电话答录机 | 狭窄、昏暗、过渡感 |
| 厨房 | 白瓷水槽、煤气炉、黄铜烧水壶、深色木柜 | 小而封闭，功能性 |
| 浴室 | 白色瓷砖、独立式洗手台、毛巾架、铸铁浴缸（如有） | 高天花板，老管道 |
| 走廊 | 窄长通道，多扇门 | 木地板，昏暗灯光 |
| 画室 | 画架、速写本、颜料架、调色盘、画布堆 | 艺术气息，松节油气味 |
| 客厅 | 老式绒面沙发、木质收音机、茶几、书架、台灯 | 暖色调，年代感 |
| 阳台 | 藤编躺椅、铸铁栏杆 | 户外，可见街景 |
| 卧室 | **不可进入**（第一章），仅外观：锁着的黄铜把手木门 | 悬念感 |

### 年代感强化元素

- **收音机**（重点年代感物件——1930 年代客厅标配）
- **煤气炉**（而非现代电炉）
- **电话答录机**（磁带式，带红灯闪烁）
- **黄铜材质**（门把手、烧水壶、灯具）
- **铸铁栏杆**（阳台，有斑驳锈迹）
- **深色木家具**（橡木鞋柜、书架）

## VN 设计映射

| 空间 | 第一章场景编号 | VN 功能 |
|------|--------------|---------|
| 玄关 | Scene 1 | 初始探索点——建立氛围与异常感知 |
| 厨房 | Scene 2 | 异常发现（粉末、滤芯、水） |
| 浴室 | Scene 3 | 异常发现（牙刷、毛巾湿度异常） |
| 走廊·卧室门 | Scene 4 | 不可进入——悬念建立 |
| 画室 | Scene 5 | 角色背景揭示 + 异常（未画过的画、地图线条） |
| 客厅 | Scene 6 | 主交互区——异常（两杯水、医学书、药瓶） |
| 阳台 | Scene 7 | 户外——粉末在光线下飘散 |
| 卧室（锁） | Scene F 触发后打开 | 艾琳娜出现——收束场景 |

### 探索触发机制

- 玄关为强制起始点
- 其余房间自由探索
- 至少探索 4 个可交互点后触发客厅电话事件
- 电话事件后触发 Scene F（她）
