# 灰山 · 山域总览

## 基本信息

| 项目 | 内容 |
|------|------|
| 名称 | 灰山（Ash Mountain / Grey Mountain） |
| 印第安旧称 | 已失传，神父提到发音近似 **"Gitsi"**——意为"呼吸" |
| 位置 | 阿巴拉契亚山脉支脉，波士顿以西约 2 小时车程 |
| 最高峰海拔 | 约 1400 米 |
| 地质 | 石灰岩为主，多溶洞、地下河 |
| 游戏地位 | 故事的核心异常源头——疗养院、教堂、山顶裂缝所在地 |

## 山体特征

### 表层：正常的山

| 特征 | 描述 |
|------|------|
| 四季 | 春夏绿意盎然，秋季红叶漫山，冬季雪覆盖 |
| 生态 | 徒步小径、溪流、小型瀑布 |
| 土壤 | 贫瘠，农业价值低，未被大规模开发 |
| 人类活动 | 山脚小镇（林业）、疗养院、教堂、偶尔的写生者 |

### 深层：沉睡者

| 特征 | 描述 |
|------|------|
| 真实身份 | 在"生命"概念出现之前就存在的、具有意识的物质 |
| 呼吸方式 | 死亡是它呼吸的方式之一 |
| 地质渗透 | 低语渗入石灰岩裂隙，被误认为风声或耳鸣 |
| 骨节说 | 山不是山——是它露在地表之上的、最末端的一根骨节 |
| 通道 | 石灰岩多孔结构 = 它的"呼吸"通道 |

## 天气与异常

| 现象 | 说明 |
|------|------|
| 峰顶乌云 | 永久性倒扣碗状乌云——不是天气现象 |
| 山雾 | 来得极快，石灰岩缝隙渗出，能见度骤降到几米 |
| 梦中雪 | 汤姆的反复梦境——山中永远在下雪 |
| 灰白色粉末 | 从山顶裂缝飘落，与疗养院病房中的粉末同源 |
| 低频嗡鸣 | 每分钟六次——与心跳同步，石灰岩传导 |
