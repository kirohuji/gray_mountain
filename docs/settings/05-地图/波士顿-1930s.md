## 城市氛围（1930 年代）

### 时代基调

| 维度 | 描述 |
|------|------|
| 经济 | 大萧条中——画廊订单归零，报社裁员，码头罢工 |
| 建筑 | Brownstone 褐石公寓遍布，哥特复兴与新古典主义混合 |
| 交通 | 有轨电车、福特 Model A、马车残余；街道以石板或砖铺为主 |
| 阶层 | 比肯山上流社会 vs 南区移民/艺术家混居——汤姆夹在中间 |
| 禁酒令 | 仍在执行，港口走私猖獗，地下酒吧遍布 |

### 视觉方向

| 元素 | 描述 |
|------|------|
| 色调 | 灰褐、深绿、砖红、黄铜、雾白 |
| 光线 | 新英格兰特有的清冷天光，冬季阴沉漫长 |
| 季节（第一章） | 深秋/初冬——下午光线暧昧，傍晚来得早 |
| 天气 | 常阴，查尔斯河晨雾，偶尔暴风雪 |
| 气味 | 海盐、煤烟、湿石板、松节油（画室）、旧木头（老公寓） |

## 与灰山的对比

| 维度 | 波士顿 | 灰山 |
|------|--------|------|
| 现实感 | 稳固、可触、日常 | 松动、梦幻、异界 |
| 时间感 | 线性、日历、预约 | 循环、梦中、模糊 |
| 人际关系 | 吉姆、哈丁、画廊老板 | 韦斯特、神父、艾琳娜的记忆 |
| 异常表现 | 电话嗡鸣、粉末、镜中延迟 | 低语、骨节、石灰岩化 |
| 叙事功能 | 安全区 → 逐渐被污染 | 源头区 → 污染溢出 |
