# 山脚小镇

## 基本信息

| 项目 | 内容 |
|------|------|
| 位置 | 灰山东南山脚，进山公路的终点 |
| 人口 | 约 300 人 |
| 经济 | 林业为主，疗养院建立后增加了少量服务业（运输、杂货、旅馆） |
| 游戏地位 | 世俗世界的最后一站——进山前最后的"正常"人类聚落 |

---

## 镇内关键地点

| 地点 | 描述 |
|------|------|
| 杂货店 | 兼营汽油、干粮、火柴——汤姆进山前最后的补给点 |
| 小旅馆 | 为探望疗养院患者的家属提供住宿——汤姆第一次探路时住过一晚 |
| 加油站 | 仅有一个油泵，老板兼营修理——"上山前加满油，山上什么都没有" |
| 教堂 | 距小镇步行约 15 分钟——详见 [山中教堂.md](./山中教堂.md) |

---

## 氛围

| 维度 | 描述 |
|------|------|
| 建筑 | 木结构为主，两三栋砖房，沿唯一一条主路排列 |
| 色调 | 风化木板灰褐色、松绿、生锈的铁皮屋顶 |
| 居民 | 沉默寡言的伐木工、满脸风霜的店主——他们知道山不太对，但从不谈论 |
| 对疗养院的态度 | 尊重但保持距离——"那地方治好了很多人，但也有些人再也没下来" |
| 对山的态度 | 敬畏——老伐木工在喝醉时会警告："别往北坡走" |
