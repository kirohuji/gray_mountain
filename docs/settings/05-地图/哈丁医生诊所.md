| 项目 | 内容 |
|------|------|
| 名称 | 罗伯特·哈丁博士私人诊所 |

## 风格细节

### 诊室氛围（核心）

| 元素 | 描述 |
|------|------|
| 色调 | 深绿（丝绒窗帘、沙发）、深棕（木质家具）、黄铜（灯具） |
| 光线 | 刻意昏暗——不让任何东西刺激到过度敏感的病人 |
| 家具 | 所有尖锐边角被圆润木质取代——不是为舒适，是为控制 |
| 声音 | 壁炉柴火的噼啪声、挂钟的滴答声、哈丁翻病历的纸页声 |
| 气味 | 旧书、皮革、壁炉木柴、极淡的消毒酒精 |

### 哈丁的风格

| 特征 | 描述 |
|------|------|
| 诊室布置 | 哈丁的扶手椅比病人沙发略高——微妙但不明显的权力梯度 |
| 说话方式 | 语速缓慢，措辞精确，"像手术刀一样将每一句话切入该切入的位置" |
| 病历记录 | 手写，钢笔，字迹小而工整——仿佛每一个字母都经过斟酌 |
| 隐藏物品 | 书架深处锁着的抽屉——伊莱沙·莫恩的部分遗稿 |

> "卡特先生，请告诉我——你看到什么了？不是你画下来的。是你看到的。"

> "梦境不是疾病。但当你无法区分梦境和醒来——那就是疾病。"

> （在汤姆离开后，独自翻看莫恩遗稿）"不是疾病。是设计。——他写的。和我导师写的一模一样。"

## 书架深处的秘密

| 物品 | 描述 |
|------|------|
| 莫恩遗稿 | 少部分未被烧毁的研究笔记——关于疗养院患者肺部的"石灰岩化"现象 |
| 莫恩的解剖记录 | 描述肺部组织中发现的微小结晶体——"具有某种不可名状的生物活性" |
| 哈丁的批注 | 用红墨水在莫恩手稿边缘写下——"精神分裂症的隐喻性表达" |

> 哈丁用纯粹的"精神分裂症"来解释导师的疯狂，拒绝触碰背后的真相。但他的手在翻到某些页码时——会抖。
