## 物品异常分类

### 粉末侵染型

物品表面或内部出现灰白色粉末——"它"的物理印记。

| 物品 | 粉末表现 |
|------|---------|
| 行李袋 | 侧面有粉末 |
| 空锅 | 底部有粉末 |
| 调色盘 | 边缘有粉末 |
| 她的水杯 | 杯底有沉淀 |
| 她的平底鞋 | 鞋底嵌砂 |
| 灰色外套 | 布满颗粒 |

### 时间异常型

物品的状态不符合物理时间规律。

| 物品 | 异常 |
|------|------|
| 烧水壶/水杯 | 十多天的室温水依然清澈 |
| 他的毛巾 | 十多天仍湿润 |
| 她的牙刷 | 完全干燥（像从未用过） |
| 滤芯 | 被清理到像新的 |

### 消失/出现型

信息或文字瞬间出现然后消失。

| 物品 | 异常 |
|------|------|
| 电话答录机 | 留言计数器从 2 变成 1 |
| 药瓶标签 | 背面出现一行字——随后消失 |
| 医学图册 | 页边出现不属于任何人的笔迹 |
| 穿衣镜 | 反射延迟一秒 |

### 无意识创作型

汤姆的双手在不受意识控制的情况下创作。

| 物品 | 异常 |
|------|------|
| 画架上的新画 | 炭笔速写——不记得画过 |
| 速写本 | 出现了"内脏图"般的线条 |
