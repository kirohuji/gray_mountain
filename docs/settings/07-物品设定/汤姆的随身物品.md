# 汤姆的随身物品

汤姆从疗养院穿回来的个人物品，伴随他进入第一章的探索流程。

---

## 行李袋

### 基本信息

| 项目 | 内容 |
|------|------|
| 首次出现 | 第一章·Scene 1（靠在鞋柜旁） |
| 外观 | 深灰色帆布袋，侧面贴白色标签——用墨水写"卡特，汤姆" |
| 来源 | 灰山疗养院的物品——不是汤姆平时用的 |
| 内容物 | 几件换洗衣物，叠得不整齐——不是汤姆的叠法 |

### 异常

袋子的侧面有一层灰白色的粉末。这是玩家在整个游戏中接触到的第一个异常迹象。

> *"你不想回忆的事情，你的手还记得。你的手指还记得从她唇间取出那颗晶体的触感。"*

### 叙事功能

- **初始触点**：玩家通过检查行李袋完成与"异常"的第一次互动
- **疗养院→公寓**：袋子是两地之间的物理连接，暗示异常随着汤姆一起回来了
- **记忆阻断**：汤姆"不想去回忆"是谁帮他收拾的——但这个人在他的行李上留下了粉末

## 速写本

### 基本信息

| 项目 | 内容 |
|------|------|
| 首次出现 | 第一章·Scene 5（画室工作台） |
| 正常内容 | 上山前的速写——波士顿街景、鸽子、艾琳娜侧脸 |
| 异常内容 | 从上山后的某一页开始——出现不是汤姆画上去的线条 |

### 异常

淡而细的炭笔线条——像一张地图。一张灰山的"内脏图"：山体内部的管道，支气管状的、分叉的、一层一层向下延伸——从山顶裂缝一直到山脚的地下。

> *"你没有画过这张图。但你的手——在你翻到这一页时——不由自主地摸向铅笔。像一个舞者听到音乐时身体本能地准备动作。"*

### 叙事功能

- **无意识创作**：汤姆的手在"它"的引导下画出了山的内部结构
- **地图暗喻**：速写本从"观察外部世界"的工具变成了"描绘不可见之物"的媒介
- **舞者比喻**：暗示汤姆与"它"之间已经建立了某种非自愿的连接

## 灰色外套

### 基本信息

| 项目 | 内容 |
|------|------|
| 首次出现 | 第一章·Scene 1（汤姆穿着） |
| 外观 | 灰色粗呢面料，领口有一圈深色汗渍 |
| 来源 | 从疗养院穿回来的 |

### 异常

第一章末（Scene 7 阳台）——汤姆发现外套上"布满了细小的灰白色颗粒——你之前没有注意到。不知道是因为光线，还是因为它们之前不在那里。"

> *"你拍了拍袖子。粉末飘散在午后的阳光中，旋转着，慢慢地——不是往下落的，是向上升的。"*

### 叙事功能

- **延迟发现**：汤姆在公寓中走了七个场景才注意到外套上的粉末——暗示异常是逐渐增强的
- **向上飘散**：违反重力——确认粉末不是普通灰尘

## 药瓶

### 基本信息

| 项目 | 内容 |
|------|------|
| 首次出现 | 第一章·Scene 1（吉姆提及），Scene 6（玩家检查） |
| 外观 | 棕色药瓶，封口铝箔完好 |
| 处方 | 哈丁医生开的——"每日一次，睡前服用" |
| 状态 | 未开封——汤姆没有吃 |

### 异常

标签背面出现了一行手写字——汤姆确定刚才没有：

> *「你喉咙里的东西不会因为吃药就消失。」*

汤姆松手。再拿起来——字不见了。标签背面空白。

### 叙事功能

- **哈丁的在场**：药瓶标注了哈丁的介入（开药）和汤姆的抵抗（未开封）
- **消失的文字**：与答录机留言计数器的变化同类——属于"瞬间出现又消失"的异常类型
- **喉咙里的东西**：指向汤姆喉咙中的结石/晶体感——"吞咽的时候会碰到"
