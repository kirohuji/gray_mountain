# 医学与遗稿

与医学、科学、疗养院相关的文献与记录——代表"理性试图解释异常"的尝试及其失败。

---

## 莫恩遗稿

### 基本信息

| 项目 | 内容 |
|------|------|
| 作者 | 伊莱沙·莫恩（灰山疗养院初代建立者） |
| 时间 | 1915–1920 年之间陆续写成 |
| 现存状态 | 少部分——莫恩发疯时烧毁了大部分 |
| 保管者 | 罗伯特·哈丁博士（锁在书架深处抽屉里） |
| 游戏中出现 | 第二章/第三章（哈丁翻阅时的片段） |

### 内容概要

| 类型 | 内容 |
|------|------|
| 患者记录 | 重症患者肺部解剖报告——描述了不应存在于人体组织中的钙质沉积模式 |
| 显微镜观察 | 晶体的手绘——不是随机沉积，"有模式，像某种语言，像某种呼吸" |
| 理论手稿 | 山是某种巨大实体的呼吸器官；"新鲜空气疗法"实际上是向实体献祭呼吸 |
| 最后笔记 | "不是疾病。是设计。"——反复出现在多页手稿边缘，笔迹越来越潦草 |

### 叙事功能

- **先例**：证明汤姆的经历不是独一无二的——有人在他之前走完了全程
- **证据**：理性观察到了异常——但观察者本身崩溃了
- **哈丁的内心**：遗稿是哈丁自我欺骗的支点——他用"精神分裂症"解释一切，但他的手指在翻页时会抖

## 《呼吸系统解剖与病理图谱》

### 基本信息

| 项目 | 内容 |
|------|------|
| 位置 | 汤姆公寓客厅书架（第二层） |
| 状态 | 被抽出一半——不是汤姆留成这样的 |
| 内容 | 肺泡结构、支气管分支模式、肺结核 X 光影像 |
| 页边笔迹 | "不是疾病。是设计。"——不是汤姆的笔迹 |
| 汤姆的记忆 | 不记得自己买过这本书 |

### 异常

这本书出现在汤姆的书架上——一个画家的书架上，夹在画册和艺术理论之间。所有被折角的页面都关于肺部。

**核心疑点**：页边的铅笔字"不是疾病。是设计。"——与莫恩遗稿中的句子完全相同。但这本书在汤姆家。笔迹不是汤姆的，不是莫恩的——是谁的？

### 叙事功能

- **空间污染**：莫恩的知识侵入了汤姆的私人空间——放在他触手可及的地方
- **读者身份**：谁把这本书放在书架上的？谁折了那些角？谁在页边写了字？
- **知识诱导**：书的存在暗示某种力量"希望"汤姆了解肺部的结构——了解"它"的呼吸通道

## X 光片

### 基本信息

| 项目 | 内容 |
|------|------|
| 首次出现 | 第二章（艾琳娜病情恶化后） |
| 拍摄地点 | 灰山疗养院或附近镇上的诊所 |
| 内容 | 艾琳娜的肺部 X 光影像 |

### 异常

X 光片上出现了无法用肺结核解释的阴影——钙质沉积形成的"分支状"结构，与支气管走行一致但超出了正常解剖范围。韦斯特医生无法解释，将其归为"罕见的并发症"。

实际上，这些阴影是石灰岩晶体的成像——是"石灰岩化"在 X 光片上的可见证据。

### 叙事功能

- **医学证据**：异常不是主观幻觉——它在 X 光片上留下了物理痕迹
- **理性限度**：即使有物理证据，韦斯特医生仍然用"并发症"来解释——理性的框架容纳不了它

## 哈丁的病历

### 基本信息

| 项目 | 内容 |
|------|------|
| 作者 | 罗伯特·哈丁博士 |
| 内容 | 汤姆的诊断记录——钢笔手写，字迹小而工整 |
| 诊断 | "精神分裂样障碍，伴严重抑郁特征" |

### 隐藏信息

汤姆的病历被哈丁放入了一个特定的抽屉——与伊莱沙·莫恩的病历放在同一个地方。

哈丁自己可能没有意识到这个行为的意义——但他正在将汤姆归档为"第二个莫恩"。
