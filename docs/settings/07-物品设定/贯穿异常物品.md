# 贯穿异常物品

游戏中最核心的异常物质与现象，贯穿多个章节，是"沉睡者"渗透现实的物理载体。

---

## 灰白色粉末

### 基本信息

| 项目 | 内容 |
|------|------|
| 首次出现 | 第一章·Scene 1（行李袋侧面） |
| 贯穿章节 | 全篇 |
| 物理性质 | 极细，滑腻，无气味，比普通灰尘更轻——在空气中向上升而不是下落 |
| 触感 | 像石粉，粘在指腹上，鼻腔吸入后有微弱的刺刺感——像极细的玻璃纤维 |
| 来源 | 灰山山顶裂缝——"沉睡者"骨节裂痕中持续逸出 |

### 出现位置

| 章节 | 位置 | 描述 |
|------|------|------|
| 第一章·Scene 1 | 行李袋侧面 | "一层灰白色的粉末。你用拇指抹了一下——很细，滑腻。不像普通的灰尘，倒更像是……石粉。" |
| 第一章·Scene 2 | 锅底 | "里面是干的……锅底有一层薄薄的灰白色粉末。和行李袋侧面的一模一样。" |
| 第一章·Scene 2 | 滤芯外壳 | "滤水器的外壳上有一层灰白色的沉淀——不是水垢。" |
| 第一章·Scene 5 | 调色盘边缘 | "一小撮灰白色的粉末。不是颜料……像一种你不认识的颜色正等着被你使用。" |
| 第一章·Scene 6 | 她的水杯 | "杯底有一层极薄的灰白色沉淀……泛出一种微弱的、珍珠母贝般的光泽。" |
| 第一章·Scene 7 | 外套袖口 | "灰色的粗呢面料上布满了细小的灰白色颗粒。" |
| 第一章·Scene F | 窗外 | "窗外开始飘雪。不——不是雪。是灰白色的细尘。" |
| 第二章·疗养院 | 病房空气中 | 艾琳娜肺部的 X 光片上出现无法解释的阴影 |
| 第三章·精神病院 | 地基管道 | 从灰山水系沿地下河运移到建筑石灰岩地基中 |

### 叙事功能

- **异常可见化**：粉末是"它"的呼吸在物理世界中最直观的残留
- **时序标记**：粉末出现在艾琳娜生病之前——暗示异常在她去疗养院之前已经侵入
- **玩家线索**：每次发现粉末都是一个新的异常证据

## 石子

### 基本信息

| 项目 | 内容 |
|------|------|
| 首次出现 | 第一章·Scene F（"口袋里的石子——那颗你不记得什么时候放进去的"） |
| 数量 | 两颗（口袋中） |
| 异常属性 | 自主振动——每分钟六次，与心跳和低频嗡鸣同步 |
| 来源 | 不明——汤姆不记得什么时候放进口袋的 |

### 叙事功能

- **共振标记**：石子的振动频率与低频嗡鸣/心跳同频——暗示汤姆的身体已被"调谐"
- **异界锚点**：石子可能是"它"放在汤姆身上的信标——或者艾琳娜放的

## 低频嗡鸣

### 基本信息

| 项目 | 内容 |
|------|------|
| 首次出现 | 第一章·Scene 1（电话答录机第二条留言） |
| 频率 | 每分钟六次——与人类静息心跳同步 |
| 传导介质 | 电话线（电磁）、石灰岩（地质）、空气（声学） |
| 主观感受 | 能在牙齿根部、锁骨后面感觉到——不是听到的，是"被共振"的 |

### 出现位置

| 章节 | 场景 | 描述 |
|------|------|------|
| 第一章·Scene 1 | 电话答录机 | "一阵极低频的嗡鸣……低沉得像从很深的地下发出来的" |
| 第一章·探索完成 | 吉姆来电 | "每分钟六次的节奏——和你的心跳一样" |
| 第二章 | 疗养院墙壁 | 石灰岩墙体中渗出的低鸣，被误认为风声或耳鸣 |
| 第三章 | 精神病院 | 石灰岩地基传导——夜晚 3 点准时出现 |

### 叙事功能

- **心跳同步**：暗示"它"的呼吸与人类的生命节律存在某种连接
- **无处不在**：跨越地理距离和媒介——不是物理声波，是某种更深层的共振

## 石灰岩晶体

### 基本信息

| 项目 | 内容 |
|------|------|
| 首次提及 | 第一章·Scene 1（低语："你的手指还记得从她唇间取出那颗晶体的触感"） |
| 性质 | 在人体组织中生长的微小钙质晶体——具有生物活性 |
| 关联角色 | 艾琳娜（肺部+唇间）、伊莱沙·莫恩（气管，致命） |
| 医学类比 | 类似硅肺病的"石灰岩化"，但晶体具有某种不可名状的生物活性 |

### 叙事功能

- **转化标记**：吸入粉末→晶体在体内生长→人体变成石灰岩的一部分
- **与山的同化**：疗养院墙壁是石灰岩——患者最终变成了与墙壁相同的物质
- **莫恩的发现**："不是疾病。是设计。"
