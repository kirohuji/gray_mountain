# 故事时间线

---

## 序章

| 时间 | 事件 |
|------|------|
| **1926 年** | 汤姆·卡特，波士顿风景画家，事业小有成就，在艺术圈站稳脚跟。 |
| **1927 年** | 汤姆去意大利旅行，在五渔村遇到艾琳娜。两人相恋。 |
| **1929 年** | 汤姆和艾琳娜结婚，她随他搬到波士顿。同年股市崩盘，大萧条开始。艾琳娜因为水土不服，总是生病。 |
| **1931 年初** | 艾琳娜确诊肺结核。 |
| **1931 年春（游戏序章）** | 韦斯特医生推荐山中疗养院。汤姆的朋友们也推荐。汤姆独自带着介绍信去山里探路，路过一座小教堂，神父主动与他打招呼认识。探访之后，汤姆开始偶尔做梦——梦中山中下雪。 |

---

## 上山

| 时间 | 事件 |
|------|------|
| **1931 年夏** | 汤姆带艾琳娜入住疗养院。大多数患者都能在这里康复。治疗期间，汤姆有时会独自到山中写生画画。他分不清是白天看到的山进入了夜晚的梦，还是梦中的山在白天等着他。现实与梦的边界开始模糊。 |
| **第 3 周** | 艾琳娜前几周也确实好转了。 |
| **第 7 周** | 艾琳娜因特殊体质（对山中空气异常敏感）病情急转直下，此后经常梦到自己死去的父亲，最后死于心脏骤停。 |

---

## 崩塌

| 时间 | 事件 |
|------|------|
| **艾琳娜死后** | 汤姆无法接受现实，在疗养院滞留数周，噩梦开始频繁。 |
| **下山后** | 汤姆终于下山，回到波士顿后，开始精神逐渐失常。他总是看到天空下雪或者是周围雾霾，或是梦到死去的妻子在呼唤他。一晚他拿起自己在山中画的画集后发现，和当初自己画的画有点不一样，多了一些他从未画过的东西：雪地里的脚印、远处的人影、山顶裂开的缝隙。 |
| **精神状态恶化** | 汤姆的精神状态越来越差，情绪经常失控，暴躁、偏执、有暴力倾向，已经影响到日常生活。 |
| **就诊** | 吉姆以及朋友带他去见心理医生——罗伯特·哈丁博士。 |
| **诊断** | 哈丁医生诊断为：现实检验能力严重受损。存在持续性幻觉。患者无法区分主观体验与客观现实。精神分裂样障碍，伴严重抑郁特征。建议住院。 |

---

## 出逃

汤姆在精神病院中逃跑，逃到了山中。他在山中走了三天。一天下着暴风雪，他带的食物吃完了。他带的火柴湿了。他开始出现幻觉——不，不是幻觉。是山在跟他说话，引导他到了一个洞穴，汤姆最后在这里找到了妻子，之后便一同死去。

搜救队找了三天，只找到了汤姆的画具和一件外套。

---

## 结局

1. **结局一（崩坏之前）**：在女主最后要不行的时候，男主决定带女主离开这里。之后女主还是死了，但是男主开始发疯以后，关于女主的记忆也消失了。

2. **结局二**：男主自杀。

3. **结局三**：男主被诊断为精神病后，一直呆在了精神病院 10 年，后因酗酒死亡。

4. **结局四**：男主从精神病院出逃到山上，最后死在了山洞。

5. **结局五**：男主从精神病院出逃到山上，最后在山洞里遇到了女主，坚持下来等到了救援队。
