## 全局触发

- 线性顺序：01 → 02 → 03 → 04 → 05
- 场景自动推进
- 第二章结束后 → 推进至 ch03（灰山）

## 一周目设计要点

- 本章承接 ch01，汤姆被吉姆带去诊所
- 01-02 为静态对话场景，节奏较慢（制造压抑感）
- 03 开始加速（空屋的恐慌）
- 04 为关键视觉异常场景（画中脚印位移 + 粉末）
- 05 为章节收束——服药→眩晕→黑屏→过度到灰山梦境
- 目标：让玩家理解"汤姆正在滑向某种不可逆的东西"
