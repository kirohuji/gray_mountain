# ch03 灰山 · 章节总览

## 场景总览

| 编号 | 场景 | 类型 | 线性韵律 |
|------|------|------|---------|
| 01 | 雪地 | 线性开场 | 梦境：黑暗→雪→巨山出现 |

| 03 | 缠绕 | 触觉恐怖 | 被缠绕、脚下是温热血肉 |
| 04 | 艾琳娜 | 核心场景 | 远处山腰的艾琳娜，无法靠近 |
| 05 | 沉入 | 收束 | 黑暗吞噬一切 |

## 全局触发

- 线性顺序：01 → 02 → 03 → 04 → 05
- 全章为梦境序列，画面风格应区别于现实场景（偏灰白、噪点、过曝）
- 第三章结束后 → 推进至 ch04（深渊）

## 一周目设计要点

- 本章为全游戏的氛围高点——纯感官压迫，无叙事对话
- 全程无任何角色对话（与梦境性质一致）
- 视觉风格建议：高对比度黑白/灰阶，模拟老电视雪花噪点效果
- 音效为核心：极低频 drone、心跳声、风声、静默的突然切换
- 目标：让玩家直观感受灰山的"存在感"——它不是背景，是活物
