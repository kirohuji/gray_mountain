## 一周目设计要点

- 本章为纯线性叙事，无自由探索、无分支、无解谜
- 场景切换通过玩家点击/自动过渡实现
- 节奏控制：01 缓慢（建立氛围）→ 02 沉静 → 03 急转（电话惊扰）→ 04 情感高潮 → 05 戛然而止
- 目标：让玩家在 5-10 分钟内理解"归途"的基本情境——汤姆回家、艾琳娜出现、发生了什么
