# 05：门铃

- 地点：哈里斯大道公寓 / 卧室→玄关→公寓外→出租车内
- 时间：深夜
- 角色：汤姆、艾琳娜（仅窗边）、吉姆
- 背景：bg_apartment_bedroom_night → bg_apartment_entry_night → bg_street_night → bg_taxi_interior
- BGM：bgm_piano_low_01（渐弱至静）
- SFX：doorbell, door_open, wind, car_door, car_engine

---

## 叙事文本

（叮——）

> 门铃响了。

（你下意识回过头。第二声门铃又响了。）

> 艾琳娜没有动，只是站在窗边看着你。
>
> 「有人找你，你是邀请了客人了？」
>
> 「我记得应该……没有……你等我一下。」

（你离开卧室，走到玄关，打开门。）

> 门外站着吉姆，呼吸有些急促。
>
> 「谢天谢地，你终于开门了。」
>
> 「怎么了？」
>
> 「你忘了吗？今天和哈丁医生有约。」

（你愣住了。）

> 吉姆拿着玄关的大衣，拉着你出来。冷风灌进楼道。你被半推着往外走。
>
> 你忍不住回过头——公寓的门还开着一道缝。
>
> 吉姆把大衣披到你肩上。
>
> 「你现在状态很差。哈丁医生已经等了你一下午了。」

（两人下楼。雪比刚才更大了。街边停着一辆黄色的士。）

（吉姆拉开车门。你坐进去的时候，忽然怔了一下。）

> 你忘了跟她说再见。你忘了问她要不要带什么东西回来。

（出租车缓缓驶离哈里斯大道。车窗外的公寓越来越远。）

> 你把脸转向车窗。玻璃上映出你自己的脸——苍白的、疲惫的、眼眶发红的。
