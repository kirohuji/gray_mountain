# 灰山 · 游戏设定与叙事风格

---

## 一、核心设定

### 1.1 世界背景

**时间与地点**
- 故事发生在 1920-1930 年代的美国。
- 主要场景：波士顿公寓、灰山（虚构山脉）、灰山疗养院、山间教堂、山脚村庄。
- 这是一个"我们的世界"——没有魔法，没有超自然力量——但**像我们的世界，不意味着它是安全的**。

**灰山**
- 灰山不是一座普通的山。它是**活的**。
- 它不主动召唤任何人。它只是在那里——等人类自己来。
- 山体内部存在一种古老的生物结构：一种以石灰岩为基础的、类似肺部的呼吸系统。
- 它通过空气中的**石灰岩孢子**与外界进行交换。这些孢子极细，肉眼不可见，但在高浓度下会呈现灰白色悬浮物。

**"疾病"的真相**
- 所谓"结核病"并非真正的结核杆菌感染。
- 它是灰山的孢子进入人体肺部后，在肺泡中**扎根、生长、重组**的过程。
- 这不是感染——这是**种植**。
- 肺部的石灰岩化是一个缓慢的、无痛的、不可逆的转化过程。最终，人的肺会被改造成山的"呼吸器官"。
- 但这个过程不是暴力破坏——它温柔地、耐心地、几乎带着母爱般地重塑人体。病人会感到"好转"，会感到"归属"。

### 1.2 核心冲突

| 层面 | 冲突 |
|------|------|
| 外在 | 汤姆试图拯救妻子艾琳娜，对抗灰山的侵蚀 |
| 内在 | 汤姆无法确定"什么是真实的"——他的感知在不可靠地移动 |
| 哲学 | 如果山不是恶意的，只是另一种生命形式，人类有权抗拒它吗？ |
| 情感 | 失去之后的执念：如果她还在，只是不再是"她"，你还要她吗？ |

## 二、叙事风格

### 2.1 核心原则

**原则一：不确定是唯一的确定**

克苏鲁式恐怖的核心不是怪物，而是**认知的不可靠性**。游戏不会告诉你：
- 艾琳娜是死是活
- 哪些事情真实发生，哪些是汤姆的幻觉
- 灰山是真实的实体，还是集体癔症

玩家的任务不是"找到答案"，而是**在不确定性中做出选择**。

**原则二：不确认，只呈现**

游戏文本只呈现汤姆观察到的事实，不提供解释。例如：
- ✅ "锅是干的。锅底有一层灰白色粉末。"（呈现）
- ❌ "锅是干的，因为艾琳娜不是活人，不需要吃东西。"（解释）

**原则三：裂缝从日常中生长**

恐怖不是从鬼屋开始的——是从一个普通的、熟悉的、安全的家开始的。茶杯、枕头、牙刷、画架——这些日常物品是最有效的恐怖载体。

**原则四：悲伤比恐惧更持久**

游戏的内核不是吓人——是**失去**。灰山是悲伤的隐喻：你爱的人在一点点变成别的东西，你无法阻止，无法确认，无法放手。

### 2.2 叙事视角

- **第三人称近距（Close Third Person）**：叙述跟随汤姆的感知和思绪，但不会超出他的认知范围。
- 文本中不会出现汤姆不知道的信息。不会出现"艾琳娜其实已经死了"这种上帝视角陈述。
- 内心独白使用斜体或特定格式，与外部描述区分。

### 2.3 碎片化叙事

信息以碎片形式散布在场景中，玩家通过探索拼凑全貌：
- 环境细节（灰白色粉尘、干涸的锅、冰凉的枕头）
- 物品描述（行李袋侧面的粉末、电话答录机的录音）
- 画作变化（速写本上的线条自动增加）
- 他人的话语（吉姆、亨利医生、迈克尔神父——每个人都只说一部分真相）

## 三、游戏机制

### 3.1 探索模式

游戏采用**2D俯视图/侧视图探索**（类似经典点击式冒险游戏），玩家在限定地图中自由移动。

**地图结构（第一章）——波士顿公寓：**

```
┌─────────────────────┐
│    [画室]  [卧室]    │
│                     │
│  [浴室]──[走廊]──[阳台]│
│                     │
│    [厨房]  [客厅]    │
│         │           │
│       [玄关]        │
└─────────────────────┘
```

- 每个房间包含若干**可交互点**（发光/高亮提示）
- 交互方式：点击物品 → 获得文本描述 → 可能触发思考或获得物品
- 部分房间需要满足条件才可进入（如：需要先找到钥匙）

### 3.2 物品系统

物品分三类：

| 类型 | 特性 | 示例 |
|------|------|------|
| **信息物品** | 提供碎片化信息，不收入背包 | 电话录音、速写本、X光片 |
| **关键物品** | 推动剧情或解锁新区域 | 提灯、钥匙、药瓶 |
| **象征物品** | 不推动剧情，但深化氛围 | 石灰岩晶体、干花、旧照片 |

物品栏位于屏幕下方，点击可查看物品详情和汤姆的内心独白。

### 3.3 "低语"系统

当玩家触发特定的异常场景组合时，画面角落会浮现极淡的灰色文字——**低语**。

低语不是旁白，不是汤姆的心理活动。它来自哪里？玩家不知道。

- 低语不提供新信息，只**强化已经存在的怀疑**。
- 低语以斜体、半透明、缓慢浮现的方式呈现。
- 例子：当汤姆摸到艾琳娜皮肤下的硬点时 → *"你摸到的不是她的骨头。是正在取代她骨头的石头。"*

### 3.4 选择分支

游戏中的选择不追求"对错"，而是追求**叙事质地**：
- 选择质问艾琳娜 → 她转移话题 → 玩家更加不安
- 选择沉默 → 裂缝继续累积 → 玩家内心的怀疑加重
- 选择离开房间 → 错过某些信息 → 形成多周目动机

选择的结果不是"好结局/坏结局"，而是**对同一件事的不同理解**。

## 四、视觉风格

### 4.1 黑白灰基调

全游戏使用**黑白灰色调**，没有任何彩色元素。

- **黑色**：恐惧、未知、山的内部、死亡
- **白色**：石灰岩粉尘、雾、病号服、艾琳娜的皮肤、雪
- **灰色**：日常、模糊地带、不确定、过渡状态

### 4.2 美术风格

- 水彩 + 炭笔 + 墨水线条的混合媒材风格
- 边界不清晰、有机、手工感
- 拒绝机械完美、拒绝动漫风格
- 人物立绘：高对比度、强光影、炭笔质感
- 背景：湿水彩晕染、纹理粗糙、有"被侵蚀"的感觉

### 4.3 界面设计

- UI 元素使用白色边框 + 灰色填充，极简风格
- 字体使用旧式衬线体（如 Caslon、Garamond），暗示 1920s 年代
- 菜单背景为静态炭笔素描
- 对话框位于屏幕底部，半透明灰底白字

## 五、音频风格

### 5.1 音乐

- 主旋律极少——大部分时间只有环境音
- 钢琴独奏为主，偶尔加入大提琴（极低频）
- 音乐不用于"烘托情绪"，而是用于**标记异常**——当音乐出现时，玩家应该感到不安

### 5.2 音效

- 日常音效：钥匙转动、水龙头、脚步声——**但都带一丝不自然的混响**
- 异常音效：极低频嗡鸣（每分钟六次）、石灰岩摩擦声、远处的唱诗声
- 低语音效：非人声，而是次声波处理过的白噪音

### 5.3 沉默

**沉默是本游戏最重要的"音效"。**

在关键场景中，所有声音突然消失——这是灰山的"呼吸间隔"。

## 六、人物档案

### 汤姆·卡特（主角）

- 职业：画家（风景画为主）
- 性格：敏感、内敛、固执。习惯于通过观察和记录来理解世界
- 困境：他的感官正在变得不可靠。他不知道哪些东西是他画的，哪些是山"替他画的"
- 象征：喉咙里的结节——他想说却说不出口的话

### 艾琳娜·卡特

- 汤姆的妻子
- 在游戏开始时（从玩家的视角）处于**无法确认的状态**
- 她的存在本身就是游戏的核心谜题
- **重要**：她的性格在患病前后是统一的——温柔、安静、偶尔倔强——这正是恐怖感的来源：她看起来完全正常

### 吉姆·莫里森

- 汤姆的好友，调查记者
- 将汤姆引向灰山疗养院的人

### 亨利·韦斯特医生

- 灰山疗养院院长

### 迈克尔·奥布莱恩神父

- 灰山教堂的隐居神父

## 七、叙事结构总览

游戏采用**非线性章节结构**，以第一章（归途）为起点：

```
[第一章：归途]          ← 游戏从这里开始
    ↓
[第二章：滞留]          ← 回忆与现实的交织
    ↓
[第三章：裂缝]          ← 日常中的异常累积
    ↓
[第四章：灰山]          ← 前往疗养院（回忆线）
    ↓
[第五章：疗养院]        ← 疗养院的真相（回忆线）
    ↓
[第六章：抉择]          ← 现在与过去的交汇，结局分支
```

**记忆层结构**：
- 第一章在"现在"（归途之后），第二章在"现在"（公寓内）
- 第三至五章是"过去"（上山前、山上、下山前的回忆）
- 第六章回到"现在"，两条时间线交会

## 八、对创作者的要求

如果你要为这个游戏编写内容，请牢记：

1. **永远不要替玩家下结论。** 你可以让玩家害怕、困惑、怀疑——但不要告诉他们"正确答案"。
2. **日常比鬼怪更可怕。** 一个空锅比一具尸体更能制造不安。
3. **细节积累而非突然惊吓。** 游戏没有 Jump Scare。恐怖来自三十个细节的总和。
4. **粗糙是风格，不是缺陷。** 不要追求光滑的 AI 生成文本。有机的、有棱角的文字更符合本作气质。
5. **记住：这是一个关于失去的故事。** 所有恐怖最后都要回到汤姆对艾琳娜的感情上——否则它只是一个廉价的恐怖秀。
