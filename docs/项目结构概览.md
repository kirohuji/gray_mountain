# 灰山 (Gray Mountain) — 项目结构概览

> 生成日期：2026-05-13

## 项目类型

**Ren'Py 视觉小说** 游戏项目，中文开发，悬疑/叙事向。

---

## 顶层目录

| 目录/文件 | 用途 |
|-----------|------|
| `game/` | Ren'Py 游戏主体 — 所有可运行的游戏资源 |
| `docs/` | 项目文档（剧本、设定、需求规格等） |
| `scripts/` | 分镜脚本 — 按章节组织 |
| `stories/` | 故事文本 — 按情节线组织（17章） |
| `settings/` | 设定集 — 世界观、角色、时间线、地图、物品、CG |
| `requirements/` | 需求规格 — 视觉风格、资产清单、LayeredImage 规格、CG 清单 |
| `changes/` | 变更日志 |
| `草稿图片/` | 草稿阶段的美术素材 |
| `chatgpt-images/` | AI 生成的参考图及 prompts |

---

## `game/` 核心结构

```
game/
├── script.rpy              # 主入口脚本
├── options.rpy             # Ren'Py 配置
├── gui.rpy                 # GUI 配置
├── screens.rpy             # 界面定义
├── definitions.rpy         # 全局定义（角色、变量等）
├── custom_config.rpy       # 自定义配置
├── chapters/               # 章节脚本
│   └── ch01_return.rpy     # 第一章：归途
├── components/             # 可复用 UI 组件
│   ├── image_card.rpy      # 图片卡片组件
│   ├── room_explore.rpy    # 房间探索组件

├── systems/                # 游戏系统
│   ├── character_manager.rpy  # 角色管理
│   ├── event_manager.rpy      # 事件管理
│   ├── exploration.rpy        # 探索系统
│   ├── inventory_manager.rpy  # 背包管理
│   ├── meta_manager.rpy       # 元数据管理

│   ├── bg/                 # 背景
│   ├── cg/                 # CG 插画
│   ├── characters/         # 角色图
│   ├── sprites/            # 立绘
│   └── ui/                 # UI 素材

│   ├── rooms.json          # 房间数据
│   └── activities.json     # 活动数据
├── libs/                   # 第三方库
│   └── vscode_renpy_warp   # VS Code Ren'Py 支持
├── saves/                  # 存档文件
├── cache/                  # Ren'Py 缓存
└── tl/                     # 翻译文件
```

## 关键特点

- **系统驱动**：探索、背包、任务、时间管理等完整系统层，不限于线性视觉小说
- **数据驱动**：角色/物品/事件/房间通过 JSON 配置
- **自定义 GUI**：房间探索、信息卡片等交互组件
- **双字体支持**：Literata + IM Fell DW Pica，支持中文
