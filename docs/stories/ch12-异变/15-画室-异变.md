# 画室·异变

## ——波士顿公寓，画室——

第二周吉姆带来的报纸还堆在玄关没有拆。哈丁医生开的棕色药瓶放在茶几上——封口完好。汤姆不记得自己上次吃饭是什么时候。

但他记得自己的每一幅画。从学院时期的港口写生，到去年在灰山的速写。他把它们从储藏室里搬出来，在客厅里一字排开。大概有三十来幅。

上午的光从北窗进来，照在第一排。港口——渔船、码头工人罢工。他记得自己画这些的时候，吉姆在旁边抽烟。

他移到第二排。意大利——五渔村的悬崖，热那亚的窄巷，艾琳娜第一次给他当模特那天下午的光。他站在这些画前面看了一根烟的时间，确认没有变化。没有多出的线条。没有石粉。画上的艾琳娜还是他画上去的那个艾琳娜。

第三排——灰山。

他把那批画从画室最里面搬出来。一共十一幅。山脚的教堂，半山腰的松林，山顶方向的乌云。画架上的写生，阳台上望出去的晨曦，雨后的碎石路。每一幅他都记得自己在什么地方、什么时间画的。

但当他蹲下来看第一幅——教堂的外观——他的手停住了。教堂门前站着一个穿白袍的身影。他没有画这个人。他画教堂的时候只画了石头外墙和灰绿色地衣。现在有一个身影站在门前。不是完整的——只勾勒了几道线，一件白袍被风微微掀起。没有脸。不是没有脸，是没有画脸——那种有意的、刻意的省略。就像教堂里那幅圣安妮。

第二幅——松林。松林没有变化。但松林上方，他没有画天空的地方，现在有东西了。是云。不是他平常画云的方式。他通常用排线，用炭笔侧面的纹理去堆——这幅上的云是点。密密麻麻的灰白点，像肺泡的剖面。像X光片上那些白斑。他知道这个纹理。他在莫恩的册子里见过——肺部钙化的显微镜绘图。那个圆形的空洞还在。在肺部正中央。圆形的，边缘整齐。和速写本上那个一模一样的尺寸。空的。在等待。

第三幅——山脊线。他盯着这幅画看了很久。山脊线是他最熟悉的笔触——他画了六年风景，山脊线是他最自信的东西。从远至近，从虚入实，一笔带过去从不犹豫。这幅画上的山不是他画的山。山脊线的起伏中多了十根——不，十二根——对称排列的弧线，从山体两侧向外弯出，像翻开的胸腔，像肋骨。不是埋在山体里的隐喻。是山的外壳被裂开了，肋骨从石灰岩裂缝里完全伸了出来，骨端的白色在月光下反射着冷光，是钙化的尖刺。肋骨之下——他跪在地上凑近了看——有一点炭笔的痕迹不是向外延伸的，是向内。在两侧肋骨围拢的正中间，山体被挖开了一个深色的腔。那个腔里，有一团极细极淡的线条，蜷缩着。不是婴儿——他已经知道了。是艾琳娜。

他把目光移到下一幅。第四幅——第五幅——第六幅——全部变了。不是在同样的位置多了同样的元素，而是每幅画都在不同的位置、以不同的方式，共同构成一个系列的进展。就像一套医学插图，从病发到末期。第一幅只是多了一个身影；第二幅多了肺泡般的云；第三幅山裂开了，露出肋骨和胸腔；第四幅——第四幅他不敢看太久——山顶的裂缝里伸出白色的枝杈，像支气管的树状分支，向下方延伸。有一根白色的枝杈穿过了疗养院的窗户。穿过的是南向的那扇——他认得那扇窗的大小和弧度。艾琳娜的病房。那根枝杈从窗户进去之后在画纸上拐了一个直角——不是自然的弧度，是几何的折角——直直通向病房内一张空床。床上有一个蜷缩着的轮廓。不是躺在床单上的。是悬在窗前那些白色的枝杈中间的。被那些东西托着。

他站起来。腿在发软。他走到那批画的最前面——教堂——然后是松林、山脊、疗养院。这些画挂成一条叙事的时间线。不是他画的时间线。是山讲述的时间线。从站在教堂门口等候，到肺部结构的浮现，到肋骨的破开，到气管的枝杈伸入疗养院的病房，到那张床上蜷缩的人形。

他不记得自己画过其中的任何一个细节。但他的落笔在上面。每一个起笔收笔都是他的习惯。炭笔是他的。纸是他的。画是他的。

他走到画室角落，从抽屉里取出莫恩的册子。翻到最后一页——*我以为是比喻。* 那一页的背面，有一张他自己之前没有注意到的图。不是印刷的。是手绘的。墨水已经褪成极淡的褐色，但线条仍然清晰——和外面那些画一样的手法。进展图解。从第一阶段的正常肺组织，到第二阶段的细微钙化点，到第三阶段的——石灰岩晶体沿气管壁向外生长，穿过软骨环，侵入周围软组织。最后一张图，石灰岩已经完全取代了肺组织。不是包裏，不是填充——是取代。每一个肺泡都变成了微小的晶洞，每一根支气管都变成了矿脉的分支。那个结构——不是破坏，是重组。是把人的肺变成了另一种东西的呼吸器官。

图下面有一行小字，字迹和正文不同——更端正，更慢，像是写的时候很用力，笔尖在纸面上停了很久。

*"它不是疾病。它是设计。我们不是在被杀死。我们是在被重新组装。"*

汤姆把册子放下。他看着这十一幅画——不是十一幅了。是十二幅。画架上多了一幅他没有搬出来的。昨天还没有，今天——他看向画架。画布上画着他自己。坐在疗养院阳台的椅子上，双臂抱膝，膝盖上摊着速写本。他身后站着一个人。穿白大褂。莫恩的脸——和楼下大厅照片上那张一模一样的脸。但嘴巴张着。嘴里面不是舌头。是白色的晶体，从喉咙深处向外蔓延，已经占据了整个口腔。

汤姆后退一步。他撞到茶几，棕色药瓶滚落在地上。他弯腰去捡，手指碰到了那颗石灰岩晶体——从艾琳娜嘴里取出来的。现在那颗大的和那颗小的粘在一起了。不是物理的粘合，不是彼此嵌入——是它们之间多了一根极其纤细的桥，同一种材料，同一瞬间从两颗石子上同时长出来的晶柱，在接触点把两边连成一体。他试图把两颗掰开。晶体是硬的。桥不是——他的拇指搓过桥面，是粉末的触感。石灰岩粉尘的触感。那层桥在他指尖散开，然后在下一秒又重新生长。和他搓下去的时间完全同步。

茶几上的药瓶滚到了沙发底下。他没有去捡。

窗外，波士顿的夜空里没有星星。但有一层极淡的灰白色悬浮物，在街灯的光束里旋转，和对面公寓的砖墙之间划出一道缓慢的、垂直的螺旋。开始往下飘，一行一行地，落在他的窗台上。
