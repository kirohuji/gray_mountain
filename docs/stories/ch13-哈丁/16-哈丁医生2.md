# 哈丁医生（故事梗概）

## ——波士顿，哈丁医生的诊室——

诊室铺着深绿色丝绒，灯光偏暗。雪光透过百叶窗，在地毯上切出苍白的线。

汤姆坐在皮质扶手椅里，膝盖上放着速写本。哈丁医生翻着病历，问他睡眠怎么样。

汤姆说：“我刚才小睡了一会。”

哈丁医生抬起眼睛：长期紧张、缺乏休息会让人恍惚，你这段时间经历太多，需要时间缓一缓。他问药按时吃了没有。

汤姆愣了一下，低声说好像忘记吃了。

哈丁没有追问，低头在病历上写字，叮嘱他这段时间不要停药，也不要一个人待太久。

诊室里只剩下座钟的声音。

汤姆低头看着速写本，说休息几天就会好的。他停顿了一下，又说：“毕竟艾琳娜已经恢复了。这比什么都好。”

房间安静下来。

哈丁的手停在病历上。过了几秒，他才慢慢摘下眼镜，轻声说：“……恢复是件好事。”那声音轻得像是不愿惊动什么。

他重新戴上眼镜，说但您自己也需要恢复。

汤姆靠回椅背，像终于松了一口气：“我知道。”

哈丁看着他，合上病历，说今天先到这里，去外面休息一会儿吧。汤姆点点头，抱着速写本离开了。

## 候诊室

吉姆坐在长椅上。汤姆走过去说：“他说我只是太累了。”

吉姆看着他，过了一会才说：“那就好。”

这时诊室的门重新打开。哈丁站在门口，请吉姆进去一下。

吉姆回头看了汤姆一眼。汤姆没有抬头。吉姆站起来走进诊室，门重新关上。

## 诊室内

安静了一会儿。吉姆低声问情况怎么样。

哈丁问汤姆回去以后有没有正常休息。吉姆摇了摇头，说这几天一直在给他打电话，但他一直没接。

窗外的雪落在玻璃上，很轻。

哈丁重新翻开病历，说最近不要让他一个人待太久，药继续吃，尽量让他规律作息。

吉姆问严重吗。

哈丁沉默了几秒，说现在还不好说。如果情况继续加重，建议住院观察一段时间。

吉姆低下头，过了很久才点了一下：“我知道了。”

诊室重新安静下来。只有窗外的雪，还在不停地下。
