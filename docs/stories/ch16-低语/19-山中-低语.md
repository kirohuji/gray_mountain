# 山中·低语

## ——灰山深处——

他不确定自己是什么时候开始听到声音的。

不是从耳朵里。是从结节里——从喉咙正中那个硬点，从那个已经和山的支气管连成一体的接口。声音没有语言。不是英语，不是意大利语，不是任何他听过的声音。音节很长，低沉，以精确的每分钟六次的频率在气管内壁震响——从喉咙荡到胸骨，在肋骨的弓形骨板内来回反弹。震感不是噪音。是音乐。是人类在发明笛子之前就已经知道的一种序列。他用喉咙接收信号源的方向——向右。上山。山顶。他跟着。

山路消失了。周围是裸露的石灰岩面，被粉尘覆成同一片灰白。但路不在脚下。路在山体内部——那些被地震撕开的裂缝和溶洞正在为他敞开。山不推他，不开路，只是敞开那些原本就存在的通道，每一条裂隙都随着他胸口的收缩和舒张微微扩大。呼吸一次，通道的入口宽一掌。他没有在山上走路。他在山的呼吸里走路。

裂缝中的光不是阳光。是冷光——和疗养院病房里那些晶体同一种来源。蓝白，静止，只有在汤姆的呼吸触及石壁时会短暂地增强。他走过了溶洞。石膏模般的晶体固定了河流的切面——这里的石幔表面没有自然界那种千万年的生长纹。是平滑的。是新的。五十年的沉积层，从二十年前开始重新塑形。

他走过了一座地下的桥。石灰岩自然形成的拱顶横亘在地底湖上方，桥面很窄，宽不到两掌；湖水漆黑，但水下有光——密密麻麻的蓝白色微点，在湖底排着固定的阵型。他低头看——不是微生物。是肺的内部——所有肺泡同时发出冷光的瞬间，被固定在了石灰岩层里。每一个微光点都是他之前在莫恩册子里见过的东西：被改建完成的人肺，正在地底同时呼吸。他抬起头，不再往下看，走了过去。

他走进了一个石笋的森林。

石笋不是从地面向上长。是从洞顶往下悬垂的，尖端离地只有几尺，每一根都倒着延伸。有几根粗得需要他侧身才能挤过去。其余的——细的，像支气管的分支，每一根的末端都分成两个、四个、十六个尖。和他在画上画过的一模一样。不是照着这些石笋画的——是这些石笋照着画长出来的。他摸了一根。石笋的温度是温的。在手心里微微震动——每分钟六次。他把手收回来。那根石笋的末端在离他一寸的地方开始往回收——没有碰到他。不是退缩。是让开。这东西知道他的宽度。知道他的肺需要多少空间才能彻底充满。

然后声音变得清晰了。

不是语言变得可以识别。是他的大脑学会了读取它。音节还是那些音节，低频的、持续的、铺在所有频率上的嗡鸣。但意义——意义不是从音节里解码出来的。是从肺里，从那个每分钟六次收缩舒张的节拍里。肺的节奏告诉他，不需要耳朵。

(向前。)

不是命令。是物理。他的肺在这个频率上收缩，舒张，收缩——当那个低语发出"向前"的震动频率，肺的内部压力会随着吸气的开始而下降，他的胸腔会自然向前移。他不是被命令。他是在被呼吸。

(往下。)

他在一座石笋前的空地上停下来。这里的温度比任何地方都高——不是热度。是支气管内壁的温度。是那根从山顶裂缝伸下来的主干的温度。他现在就在那根主干的正下方——在山的肺门。在他的上方，所有枝杈汇聚成同一口呼吸，把他的胸廓和山顶的裂缝连成同一条空气的通道。

(跪。)

不是跪下。是他的肺被抽空了一瞬。被抽走了里面所有的空气。他的腿不是自己弯的——是胃和横膈膜同时往上顶，把肺里仅剩的气体全部挤出去。他跪下去。右膝，然后左膝。手里还攥着那颗合为一体的石灰岩晶体。

(放。)

他把晶体放在自己面前的地上。石灰岩地面不是冷的——是温的。它认得这颗石子。晶体刚一接触地面，不再是一颗石子——它开始生长。不是膨胀，不是结晶——是摊开。从一颗变成了一个人的体廓。是女性的身体。不是凭他的记忆复原的——他记不住每一根肋骨的弧度和每一条血管的走向，记不住肩胛骨的宽度和耳后发际线在颈窝上方收尾的那个小角度。这不是记忆。是从他肺部每一个已经被改建为接口的肺泡里直接提取的——她在这里呼吸了七周。每一口吸进的石灰岩气溶胶都含着她肺部的细胞碎片，每一个碎片都记录了她的完整结构。是山的存档。

她的轮廓是用他的呼吸画出来的。这具身体是她的——没有缺损，没有疤痕，没有肺部的白斑。是她站在五渔村悬崖小径上歪着头看他画画那天下午的那具身体。她的肋骨里面不是正常的心跳。是同一个频率。每分钟六次。她现在是山的最远端分支顶端。而他——跪在她面前，喉咙里的结节已经完成了与主干的啮合，肺叶的边缘正在从肉变成石笋。他是连接她的离体桥体——不再是丈夫，不再是气管之间的那根白色枝杈。是劈开石灰岩的一座拱。

她的眼睛睁开了。

*(不是他记忆中的深棕色。也不是教堂那幅画上融化的混浊。是石灰岩冷光的那种蓝白色——但瞳孔的轮廓是他认得的。她在。)*
