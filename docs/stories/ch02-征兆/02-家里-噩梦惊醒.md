# 家里

## ——家里——

艾琳娜：嘿，亲爱的！

汤姆被妻子推醒，喘着粗气睁眼，还没反应过来。

他马上从被子里坐起来，握住妻子的手，温热的、柔软的，像是梦里感受到的那样。

艾琳娜：天呐，你整个人像是从水里捞出来的,出了这么多冷汗。做噩梦了？

妻子冰凉的手贴上他的额头，汤姆抖了下。

汤姆：不，没事,我只是做了一个噩梦。

但是那是个梦吗？

汤姆尚还未从噩梦中缓过神，那梦太过真实，导致他现在呼吸还觉得困难。

艾琳娜担忧地看着他，语气关切。
艾琳娜：你一定是压力太大了，我去给你倒杯热水。

她摩挲着打开台灯，那从老房子里带来的黄铜底座的老台灯。昏暗的灯光下，卧室的周围显得更加幽深，只有尘埃在空气里滚动着。

汤姆拦住了妻子起身的动作。
他知道妻子的病情，夜里本就浅眠，如今被自己吵醒……

汤姆：不，还是我自己去吧。

他轻轻摁住妻子的肩膀，把被子往上盖。

艾琳娜正欲说点什么，可随即撕心裂肺的咳嗽迫使她不得不捂住嘴。

像是要把肺咳出来的程度，让汤姆心里一紧。

艾丽娜咳嗽了一会儿，汤姆赶紧拍了拍她的背。

艾琳娜: 我没事，只是咳嗽。

汤姆: 你需要好好休息。

汤姆离开卧室，去厨房倒水。
