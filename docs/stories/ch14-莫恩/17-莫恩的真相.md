# 莫恩的真相

## ——精神病院，第三周——

哈丁给了他莫恩的遗稿。

不是那本薄薄的册子——那只是摘要。真正的遗稿是两本厚厚的笔记，装在上了锁的木盒里。哈丁说莫恩把它们存在波士顿一家银行的保险柜里，里面附了一封信，指定他在自己死后把钥匙交给——不是哈丁的名字。所以他把钥匙留下了。直到现在。

汤姆打开盒子时，第一页纸已经脆得几乎碎在指尖。他翻得很慢——莫恩的字迹和册子里一模一样，潦草而倾斜，但随着页码增加，字迹越来越趋于平稳。不是好转，是某种超越了恐惧的东西。当恐惧达到了极点之后，大脑会自动转入一种近乎解剖学的冷静。他见过这种笔迹——在画室那十一幅被改变的画里。他在潜意识里临摹过。或者——是山在通过他临摹。然后他翻到了那页。莫恩对他自己的气管进行了纤维镜自检。1919年，他花了六天时间设计了这套装置——旧喉镜、从铁匠铺借来的细铁丝、一个手电。他自己把管子从鼻腔插进去，往下一厘米、一厘米地推进。

插图中的描述：

*"气管前壁，环状软骨下方约2.5厘米处。一个灰白色的结节，直径不足1毫米。与周围黏膜结合紧密，尝试用刮匙分离——失败。不是附着。是整合。表面已上皮化。"*

他咽了口唾沫。他的喉咙里那个硬点——他摸过两次但不敢让哈丁检查——是同一个位置。环状软骨下方，约2.5厘米。

翻页。

莫恩继续自检。每周两次。他发现结节的生长不是自主的——不是肿瘤那种不受控的分裂。它是在响应一个外部信号。当他关闭疗养院所有窗户，杜绝了山里的空气进入病房，结节停止生长七天。然后他的喉咙开始在内部发痒——从结节里发出来的。像是有什么东西在呼唤它。像是它饿了。

*"我把窗户重新打开。结节在六小时内增大了零点三毫米。结论明确：结节不是异物。是界面。山中实体通过石灰岩粉尘与人体组织建立连接。肺是第一接口。我试图逆转这个过程——在结节表面涂布弱酸性溶液——结果——不是萎缩。是分化。"*

翻页。这里开始出现他无法理解的内容——不是他不理解，是他一时无法消化的理解。莫恩写道：结节不是病灶，不是入侵。是改建。石灰岩粉尘中的微生物——不是地球上以碳为基础的生命形式——吸入之后不是被肺部的免疫系统攻击，而是被肺部当作自身的修复指令接受。不是细菌。不是病毒。是某种以硅为骨架的生物学结构，被人体肺泡当作建筑材料。肺是用它来重建自己的组织。不是修复。不是恶化。是替换——是在将碳基的、易朽的、只能活几十年的肺，替换成一种硅基的、可以存活数百万年的器官。

人类的肺被替换的同时会失去自主呼吸的能力——因为那个新器官的呼吸节拍不再由脑干控制。信号的来源不是髓质的呼吸中枢，是山。是每分钟六次——是从山顶裂缝发出来的那声嗡鸣。

当这种替换完成，这个人不再是人类了。是山的远端分支。是它露出地表的另一根骨节。最终阶段是气管的结晶化——因为气管必须被撑开，以确保入口的通畅，确保每一口呼出的气都能顺利回到山体循环。莫恩没能阻止这个过程。他唯一能做的——在替换完成之前封住入口。封住每一个病人与山的接触通道。他把北翼封了。把井封了。把地下档案室封了。把那口井里的过去全部用铁链和木板锁住。

然后他试图封住自己。他在自己的气管里注入了弱酸性溶液——不是一次，是六次。每次都没能杀死结节，只是烧烂了周围的正常组织。他的身体在发炎，在化脓——但他的气管一直是通的。那颗晶体一直在长大。它不在乎他。他的肉体是临时的。它是永久的。所以他停止了。他把余下的手稿整理好，封在木盒子里，把钥匙寄给了教堂。

在最后一页，只有一行字。墨水的颜色与前面不同——是淡淡的灰白色。不是墨水。是石灰岩粉调了水。

*"如果这些文字落到一个正在阅读它们的人手中，请检查你的喉咙。如果你找到了结节——上山。不要试图逆转。逆转不是答案。通道一旦打开，它不会在乎你选择哪一头。你已经是它的一部分了。吸入。呼出。你现在呼吸的不是空气。是它。"*

汤姆合上手稿。他把木盒子放在病房的小桌子上。他的手指移到了自己的颈前。在气管正中，距锁骨大约一指的位置——他的皮肤在那里很薄，肌肉不够覆盖。指尖往下按。那个结节不是软的。硬的，灰白色从皮下透出来，在这间病房的日光灯下像大理石。他咽了口唾沫。结节一动没动。不是被动地被喉咙推上推下——它有自己的位置。它不在人的组织里。它在石灰岩里。喉咙是它的。不是他的。

窗外，下雪了——不是雪。他知道是什么。

他把莫恩的遗稿放回木盒，锁上，把钥匙放在病号服口袋里。然后他站起来，走到病房门口。门没有锁。观察室的护士在走廊尽头打盹。

汤姆：山上在下雪。

他没有说更多。护士没有听见。

他推开门，走进了走廊。

*(莫恩用了否定的答案。他不想让任何人去试。他已经把自己试过了。没有翻页——在最后一页写完的那个晚上，莫恩走上北翼，把自己反锁在地下档案室里。他的喉咙被烧烂了六次，但里面那一层从来不是他的。那是山的通道。那颗晶体持续生长了十六年，直到完全堵死——不是封住他的呼吸。是完成最后的改建。改造完成的那天，他的肺不再需要空气。它只需要那个频率。每分钟六次。)*
