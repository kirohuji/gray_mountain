# 归途

## ——波士顿，下山后——

哈里斯大道的公寓和他离开时一模一样。

吉姆帮他开了门，把行李放在玄关。客厅的窗帘拉着，空气里有久未通风的沉闷。厨房的水槽是干的，烧水壶安静地坐在灶台上——底部有一圈干涸的水垢。

汤姆站在客厅中央。

吉姆：我明天再来看你。药在茶几上——哈丁医生开的，每晚一片。

吉姆走了。门锁咔嗒一声合上。汤姆独自站在公寓里。周围的一切都在熟悉的地方——沙发、书桌、茶几、台灯。

汤姆探索了一会后,突然感觉到头发晕,视线开始有些模糊.

这时电话响了。

他接起来。吉姆的声音——隔着很远的距离，像是从隧道尽头传来的。吉姆说昨天打了好几次他都没接，说哈丁医生的预约。然后声音中断了。不是信号不好——是被什么东西覆盖了。电话里传来一阵低频的嗡鸣。

他拿着听筒。那嗡鸣持续了几秒。然后——

他听到了别的声音。

从卧室传来的。很轻。是布料的窸窣，是指尖翻过书页的声音。

他放下电话。他推开卧室的门。

艾琳娜坐在床边。

她穿着那件淡色的家居裙。头发恢复了光泽——不是疗养院末期那种干枯——是更早的。是他们在波士顿搬进这间公寓的第二年冬天，她裹着毯子坐在北窗下看他画画的样子。皮肤有血色。嘴唇是粉的。呼吸平稳。他看着她的胸廓——起伏。

艾琳娜抬起头对他笑了。

艾琳娜：你怎么去了这么久。我以为你只是去买颜料。

汤姆站在门口。

汤姆：我去了——

他突然停顿下来。但是他依稀记得之前发生的事情。他跪在碎石路上痛哭，跪了很久。可她现在却坐在他面前。胸廓在起伏。

艾琳娜：你去了哪里？

她站起来，走到他面前。她的手指贴上他的脸颊——温的。软的。他握住那只手，翻过来看她的掌骨——皮肤下面，指节的骨缝之间，没有硬点。没有石灰岩。没有沙。

汤姆： 你恢复好了？

艾琳娜歪了歪头。

艾琳娜：医生说恢复得很好。你怎么了。你看起来像是见了鬼。

他突然抱住她。他崩溃了。他哭得说不出话。

汤姆：我以为你死了。

她愣了一下，然后笑了——那种"你在说什么呀"的笑。

艾琳娜：说什么傻话呢？你最近有些健忘呀，我不是已经恢复了吗？

汤姆：什么时候？

艾琳娜：前段时间——你不是陪我去疗养院了吗？然后就好了呀。

她的眼睛没有躲避。她的语气里没有迟疑。但他不记得。或者他记得的不是这样。他记得跪在路边，哭到喘不过气，有人把他从地上拉起来。

汤姆：但是……但是我记得当时我跪在路上……

艾琳娜轻声说：你一定是记错了。我现在不是好好的吗？

这时他看到了——在床头柜上，摊着他的速写本。翻到的那一页，是艾琳娜在五渔村的速写。圣徒节的夜晚。那幅他最喜欢的画。

他记得这幅画。纸面泛黄，炭笔线条被时间摩擦得有些模糊。画上的艾琳娜——她当时在跳舞，手臂向上扬着，脸上是那种被烈酒染红的笑。

然后艾琳娜推开了他,站到窗边，背对着他，看着外面波士顿的夜。她的背影被窗外的街灯投下的光勾出一个柔和的轮廓。

然后她转过身。

她的脸——在光里，在黑暗前。台灯的光把轮廓照出来，是他在教堂里见过的那种光线。他盯着她的嘴角。嘴角是弯的。眼睛是亮的。呼吸——胸廓在起伏。
窗外，波士顿开始飘雪。不是雪。是灰白色的细尘，落在窗台上没有声音。

但是我头越来越痛,困得要死,我直接倒在床上睡着了...
