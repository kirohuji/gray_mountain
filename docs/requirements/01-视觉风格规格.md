# 视觉风格规格书 — 《灰山》

> 版本：v1.0 | 最后更新：2026-05-01

---

## 一、风格定义

### 1.1 核心美术风格

**混合媒材：水彩渲染 + 墨线勾勒 + 炭笔阴影**

| 层面 | 技法 | 视觉作用 |
|------|------|----------|
| 底层 | 水彩渲染（watercolor wash） | 背景氛围、雾气、天空、远山 — 湿润、渗开、不可控 |
| 中层 | 炭笔阴影（charcoal shadow） | 恐怖元素、阴影蔓延、山体纹理 — 粗糙、粉末感、可抹开 |
| 上层 | 墨线勾勒（ink line art） | 角色轮廓、建筑结构、关键细节 — 利落、手工感、不完美 |
| 基底 | 手工水彩纸（rough watercolor paper） | 所有图层共享纸纹理 |

### 1.2 色调

- **主色调**：单色灰（monochrome greyscale）
- **暖色倾向**：sepia tone（棕褐）, umber（赭褐）, muted tones（柔和色调）
- **禁色**：任何鲜艳色彩、纯黑纯白（用深棕和米白替代）
- **色调参考**：1920-30年代自然主义野外速写簿

### 1.3 反 AI 味策略

| AI 常见特征 | 本项目的反制 |
|------------|------------|
| 完美平滑线条 | → 墨线刻意不完美：`uneven ink flow, dip pen lines, organic` |
| 均匀纹理 | → 水彩渗色不可控：`bleeding edges, pigment granulation, water stain` |
| cel shading 二次元 | → 炭笔柔和过渡：`charcoal smudge, powdery texture` |
| 光滑数字感 | → 纸纹理穿透：`rough watercolor paper, paper grain visible` |
| 机械对称 | → 手工不对称：`handmade, loose brushwork` |

### 1.4 与 ess UI Theme 的协调

ess 主题的 weathered/gothic 风格与本混合媒材风格**兼容**：
- UI 的"风雨侵蚀纹理" → 对应水彩的渗色和纸纹
- UI 的"纤细装饰白线" → 对应墨线的利落勾勒
- UI 的"深黑背景" → 对应炭笔的浓重阴影
- UI 的 IMFellDWPica 衬线体 → 对应墨线的手工书写感

## 二、角色视觉规格

### 2.1 通用立绘规格

- **格式**：WebP（lossless）
- **分辨率**：832 × 2176 px（全身像）
- **分层**：5层（body / head / eyes / mouth / extra）
- **背景**：生成时纯白背景，便于去底提取
- **线条**：墨线不完美，允许轻微颤抖和渗墨
- **上色**：水彩渲染，允许渗色超出轮廓线

### 2.2 各角色表情/姿势需求

| 角色 | 表情数 | 额外层 | 特殊需求 |
|------|--------|--------|----------|

| **艾琳娜** | 5（微笑/咳嗽/担忧/安睡/鼓励） | 蓝唇、脸红、咳血手帕、肋骨突出 | 躺卧姿势（病房） |

| **神父** | 2（凝视/悲悯） | 提灯 | 阴影中姿势 |
| **哈丁** | 1（临床精确） | — | 坐姿、诊室背景 |
