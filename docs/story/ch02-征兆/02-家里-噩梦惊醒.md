# 家里

## ——家里——

艾琳娜：嘿，亲爱的！

汤姆被妻子推醒，喘着粗气睁眼，还没反应过来。

他握住妻子的手，温热的、柔软的，像是梦里感受到的那样。

艾琳娜：天呐，你整个人像是从水里捞出来的。做噩梦了？

妻子冰凉的手贴上他的额头，汤姆抖了下。

汤姆：不，没事。

那只是个梦吗？
汤姆尚还未从噩梦中缓过神，那梦太过真实，导致他现在呼吸还觉得困难。

艾琳娜担忧地看着他，语气关切。
艾琳娜：你一定是压力太大了，我去给你倒杯热水。

她摩挲着打开台灯，那从老房子里带来的黄铜底座的老台灯。昏暗的灯光下，卧室的周围显得更加幽深，只有尘埃在空气里滚动着。

汤姆拦住了妻子起身的动作。
他知道妻子的病情，夜里本就浅眠，如今被自己吵醒……

汤姆：不，我自己去吧。

他轻轻摁住妻子的肩膀，把被子往上盖。

艾琳娜正欲说点什么，可随即撕心裂肺的咳嗽迫使她不得不捂住嘴。

像是要把肺咳出来的程度，让汤姆心里一紧。

没由来的，他想起梦里那诡异的山。
那起伏很轻、很缓，但那种它正在呼吸的感觉，就像是有人拿针在扎他的脑子。

不疼，但存在着、持续存在着，让汤姆无法思考其他。

够了，停下这不切实际的想法吧。

汤姆在心里呵斥自己，掀被下床，他走到厨房倒水。
