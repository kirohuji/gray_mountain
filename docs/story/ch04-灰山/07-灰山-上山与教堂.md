# 灰山·上山与教堂

## ——灰山——

这天十分阴冷。

站在山脚下抬头，甚至看不见上面的景色。

朦胧的雾飘在半山腰，宛若神秘的面纱，引诱着无辜的人探寻未知。

刚下过雨的灰山泥泞不堪，他不得不十分小心，防止自己脚滑摔倒。

就这样走走停停两个小时，汤姆已累得气喘吁吁。

他不得不承认，自己在画室待的太久，体力已大不如前了。

而每走一步，空气就粘稠一分，让他变得难以呼吸，就像是在试探。

汤姆将这一切归咎于山上空气稀薄。他不愿吓唬自己，特别是在阴冷的山里。

就在他艰难上行时，雾里模模糊糊的出现了一座教堂。

它安静地伫立在原地——或许可以说，是伫立在时间里。

它几乎是隐形的，消失在灰白色的雾气中，像是某种正在被缓慢腐蚀的巨型生物的残骸。

石头砌成的外墙覆盖灰绿色的地衣，让汤姆想到慢性皮肤病人的模样。

时间侵蚀的石墙坑坑洼洼，但孔洞却是光滑的。苔藓从里面长出来，细密的、泛白的，像死者的胡茬。

或许还有更贴切的说法，但汤姆想不起来。

再走近一些，他才看见原来那顶上是蒙灰的玻璃。

只有特定角度才能被察觉的玻璃。

那并不神圣，反而有诡异的荒芜感。
因为他潜意识里觉得，这座教堂是山里"长"出来的。

汤姆足足在原地踌躇了半小时。

可最后，他还是选择休息，进入了教堂。

"吱呀"一声，门被推开了。
并没有他想象中沉重，倒像是无用的掩盖，在心理上阻止他进入。

教堂里有些昏暗，微弱的光透过玻璃，照亮上头画着的东西。

圣母玛利亚？
不，那只是个怀抱婴儿的女人。

汤姆从没见过如此诡异的画。

她的脸——如果还能被称之为脸，已经融化成背景。可唯独那轮廓还在，形成令人头皮发麻的错觉。

她好像正在笑。
背后的透光让她被笼罩在阴影里。

可她微微上扬的，不属于圣母的唇角，就像是在怜悯汤姆。

？？？：您是迷路了吗。

汤姆被这沙哑的声音吓了一跳。

回过头，身披白袍的老人正站在门内侧的阴影中。

他颧骨高耸，眼窝深陷，每走一步都带着沉重的呼吸。

汤姆看着他走过来。

老人面无表情地看着他。

迈克尔：我是这里的神父，迈克尔·奥布莱恩。

汤姆：奥布莱恩教父，您好。
汤姆：您或许知道……疗养院该怎么走。

声音被墙壁吸收，没有留下回音。

迈克尔很慢地点了下头。

他的脸隐没在灰色的空气中，眼睛转动着看向那壁画。

迈克尔：很多人上山。

神父突然开口。
没有起伏，不是冷漠，只是在陈述事实。

汤姆没有答话，静静等待他再次开口。

迈克尔：但只有一部分人下山了，很少的一部分。

说完，神父咳嗽了几声，举起一盏灯递到汤姆面前。

这近距离的灯光才让汤姆看清，迈克尔神父的表情竟有几分悲悯。

迈克尔：这盏灯，你拿走吧。

迈克尔：趁还没天黑抵达疗养院——山里的夜晚，远比你想的危险。

意味深长的话让汤姆立刻回忆起那个诡谲的梦。

对眼前这个陌生的教父，汤姆产生了退却的想法。

他拿起提灯，深呼吸之后，转身离开了。
走出一段距离后他回头看，那座教堂已经消失在雾气中。

没有关门的声音。

那雾气仿佛有着重量，像大张着口的怪物正等待汤姆进入。

他的背影消失在其中。
存在也消失了。

此时，灰山开始沉重、缓慢地呼吸。
