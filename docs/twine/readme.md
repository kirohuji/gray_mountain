## v2.0 扩展内容 (2026-05)

### 字数对比
- v1.0：约 3,800 汉字，55 Passages
- v2.0：约 18,700 汉字，94 Passages
- **增幅：约 5 倍**

### 新增互动元素
- **新增变量追踪**：`$met_nurse`、`$heard_whispers`、`$saw_shadow`、`$trust_henry`、`$night_explored`、`$found_journal`、`$saw_basement`、`$held_hand`、`$woke_screaming`、`$lie_to_elena`、`$chose_to_stay`、`$chose_to_run`
- **条件分支增强**：基于 `$fear` 值、先前选择（`visited:`）、物品持有状态等触发不同文本
- **多结局设计**：
  - 第六章「留下来」结局 — 选择留在疗养院
  - 第六章「下山」结局 — 带艾琳娜逃离

### 恐怖元素强化
- 血肉之墙的生物恐怖描写
- 迈克尔神父与灰山融合的身体恐怖
- 护士编号代替姓名的体制恐怖
- 亨利医生从理性到疯狂的心理转变
- "肺是入口"的寄生概念
- 影子的独立性暗示
