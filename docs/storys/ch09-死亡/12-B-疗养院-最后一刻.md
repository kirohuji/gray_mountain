# [Version B] 疗养院·最后一刻

## ——第十周——

她离开的那天，没有下雪。

夏日的阳光照常从大窗户涌进来。蜜色的光落在白色床单上，落在她凹陷的脸颊上，落在她紧闭的睫毛上。病房里有消毒水的气味，有松树从窗外探进来的清香，还有——还有她呼吸的声音。

很轻，很慢，像风穿过石灰岩的缝隙。

汤姆坐在床边。他已经不记得自己在这里坐了多久。他握着她的手——她的手指比昨天更凉了一些，骨节之间的硬点比昨天更大了，突出来顶着皮肤。

他不敢捏。

韦斯特医生早上来过。他听了很久，然后摘下听诊器，什么也没说。玛格丽特护士进来换床单时眼睛是红的。贝茨太太让人送来了一枝干薰衣草——"给她放在手上。"信纸上只写了这一句话。她本人没有来。她已经不能下床了。

艾琳娜今天醒过两次。

第一次是在清晨。

艾琳娜：汤姆……我想喝点水。

他端着水杯，小心地扶起她的头。她的脖子细得好像一折就会断。她咽了一下——他听到了。除了她吞咽的声音之外还有一个声音。很细，很脆，像是两颗沙粒在她喉咙深处彼此摩擦。

然后她又闭上了眼睛。

第二次是午后。

她突然睁开眼，眼睛亮得惊人。不是过亮——就是亮，真正的、带着意识的亮。她看着他，看了很久。

艾琳娜：汤姆。帮我——把窗户打开。

汤姆站起来，走到窗前。巨大的窗页向外推开，山间的风涌入病房。带着松脂的气味，带着湿石灰的微腥。还有更细的东西——肉眼几乎看不见的灰白色微粒，悬浮在空气中，从山顶的方向像花粉般飘落。

艾琳娜深深吸了一口气。那是她几周以来最深的一口呼吸——胸腔鼓起来，锁骨下的凹陷被空气填满。

艾琳娜：真好闻。

她微笑了一下。

那是她最后一次微笑。

*

## ——然后——

一切发生得太快。

她的眼睛还在亮着，嘴角还弯着，然后——

然后她的眼睛忽然不动了。不是闭上，不是闪烁。就是定格在那里——像画布上画上去的，像玻璃珠。嘴角的弧度还挂在脸上，但笑容没了。消失了。像有人从画布上擦掉了灵魂的那一笔。

她的身体僵了一下。背弓起来——幅度很小，像是被一根看不见的线从胸口提起。脖颈向后仰，锁骨凸出一个尖锐的角度。病号服下，他能看到她的肋骨一根根凸起，随着胸廓的徒劳起伏——然后，不动了。

汤姆站起来。椅子被推倒在身后。

汤姆：艾琳娜——！

他按住她的肩膀。她的肩膀还是软的，还带着体温。但她的瞳孔——他看到了——固定不动，放大，边缘染着极淡的灰白。不是云的倒影。是石灰岩粉尘沾在了角膜上。

他按呼叫铃。按一次，按两次，按三次。铃声响了又断，断了又响。他把她的手放在自己手心——手还是软软的，手指微微蜷着。

韦斯特医生冲进来。后面跟着玛格丽特护士。韦斯特弯下腰，听诊器贴上艾琳娜的胸口。沉默。五秒。十秒。

韦斯特医生直起身。他看着汤姆，摘下眼镜。

韦斯特：心跳已经停了。

他在说什么。心脏骤停。结核影响了自主神经。体质特殊。汤姆没有在听。他看着艾琳娜的脸——她的嘴唇微微张开，下唇和牙齿之间有一个什么东西在反光。很小，不到米粒大小。灰白色的。半透明。

韦斯特医生转过身去写死亡记录。玛格丽特护士在哭。

汤姆伸出手。他的拇指和食指从她的唇间取出了那个东西。冷的。硬的。不是玻璃。不是沙。是晶体——规则的、有棱角的、刚成型的石灰岩微型结晶。他把它攥在手心里。没有人看见。

玛格丽特护士轻轻将艾琳娜的手放在身侧。她把那枝干薰衣草放在她的掌心里。

汤姆站在病房中间。病床上已经空了。他摊开手掌——那颗晶体在他的掌心里，温热尚未散尽。从一个人的气管深处长出来的石头。莫恩的册子里写过的。他以为莫恩是个疯子。他攥紧拳头。

然后他看到了矮柜上的速写本。

他拿起本子。翻到写生的那一页——教堂写生，山脊线。那是他以为他画的内容。现在山脊线已经不再是山脊线了。肋骨——清晰得像解剖课上的石膏模型，一根一根以精确的弧度向内弯曲。在肋骨保护的内侧，画着两张肺的剖面——左肺铺着密密麻麻的斑点，右肺是空的，被什么东西侵蚀成了一个大洞。那个洞的边缘不是锯齿状的——是圆形。是有意为之的。像鸟巢。像床。像为某样东西专门安排的、尺寸刚好的卧槽。右肺下方，字迹潦草但用笔极深——像是一个人被压在重物下拼命向外面写字：*它已经不在肺里了。它现在在空气里。*

他不记得自己写了这几个字。他甚至不记得自己会写这么工整的拉丁字母。

他翻到最后一页。

那一页他从未画过。

上面只有一个轮廓。一个蜷缩着的女人，睡姿，包裹在极细的灰白色微粒之中。线条每一根都用了最轻的笔触——不是素描，是沉积。石粉是落在纸上然后自行排成这个形状的，不是被画上去的。他自己知道——他用了炭笔。他从来没用过石粉。小腿以下已经开始模糊——那些细微的颗粒正在继续坠落，被看不见的手操弄在纸面上自行按着这个轮廓的边界堆积。正在漫过膝盖，沿着骨节，一路往上。他不确定明早再翻开这一页的时候她还剩下多少。

不是婴儿。

是艾琳娜。

他把那颗石灰岩晶体放在素描本旁边。晶体和纸面的石粉在同一个频率下微微震颤——不是他的震颤，是它们自己的。是每分钟六次。是墙壁里那个节拍。现在不需要贴在墙上了。

他走出病房。玛格丽特还在等他。韦斯特医生站在走廊尽头，背对着他，双手插在白大褂的口袋里，一动不动。

汤姆走过三层楼的走廊。灰白石墙，高挑天花板。他经过那扇锁着的铁门——旧档案室。门缝下面的冷空气比任何时候都更浓。地面上的污渍似乎比昨天更大了一圈。

他经过贝茨太太的病房。门开着。她坐在窗边，还是那个姿势。听到他的脚步声，她没有转头。

贝茨太太：她走了。

汤姆停住。

贝茨太太：你知道莫恩医生为什么要把东西扔进井里吗。不是毁灭证据。是储藏。石灰岩——会保存东西。它会吸。吸水分，吸温度，吸记忆。他扔下去的那些纸——如果现在有人下井去找，还能读到每一个字。每一个字都会是清晰的。石灰岩不会让你忘记。它只会让你改变。

她把手从膝盖上抬起来。她的手指——五指并拢，从指尖到手腕，皮肤下面浮着一层细密的灰白纹理。不是血管。是大理石的纹路。

贝茨太太：你也该走了。她不在病房里了。她在那本子里。在那颗石子里。在空气里。她还在呼吸。只是不是你记得的那个肺了。

汤姆走出疗养院的大门。

山里的空气涌上来。凉的，湿的，带着石灰岩的微腥。他站在门口，面前是那条碎石路，下面是村庄，更下面是教堂，更上面——山顶的方向，乌云沉沉，石灰岩粉尘从峰顶的裂缝中持续飘落，将整个山谷笼罩在一层极淡的灰白之中。

他跪下。

手心里攥着那颗晶体——从她的气管深处取出来的。他的食指和拇指之间，晶体的棱角刺进了皮肤。不是痛。是确认。是物理性的证明——她最后留下的不是记忆，不是照片，不是画。是石头。

山风吹过来，翻动他手中的本子。他把那本莫恩的册子从口袋里掏出来——封面还是凉的。第一页上那些褪色的字迹现在看起来比刚才更清楚了。不是错觉。是那层褪色的褐正在变淡。字迹在恢复。石灰岩在返还储存在里面的东西。他不用读第二遍——他背得出来。*我以为是比喻。*

口袋里的石子是温的。他自己的血濡在石子上，把它染成浅红。光线透过山脊的边缘，在他掌心的影里缓缓飘浮。阳光，松脂，湿石灰。石粉落在他的肩头，很轻。他开始咳嗽，手帕上没有血。只有一粒极小的、半透明的砂。他把它也攥在左手心里——和那颗大的放在一起。

他跪在地上，低着头。

速写本摊开在碎石上。石粉继续在纸面上沉积，膝盖、腰、锁骨、下颌——她还在画里面，还在变成石粉，还在呼吸。风穿过松林，穿过石灰岩的孔洞——频率很准，每分钟六次。他自己的肺也在这个频率上，吸，呼，吸。

他无法呼吸。
