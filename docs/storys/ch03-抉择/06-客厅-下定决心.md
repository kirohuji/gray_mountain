# 客厅·下定决心

## ——客厅——

尖锐的哨声在寂静的夜里突兀响起。

汤姆被拉回思绪。

起身，关火，倒水。

他端着水杯，升腾的热气模糊视线。窗外的夜色依旧浓稠。

他不知道自己在外站了多久。

福特医生的声音还在脑子里——"已经不是早期了"。那个摘眼镜的动作、沉默的间隙、推过来的那封推荐信。他没有直接催促，只是说"去看看"。可越是平静的劝说，越是让人无法反驳。

他转身，但没有马上回卧室。他走到那张橡木小书桌前，拉开抽屉。

里面堆着这几日攒下的东西。福特医生的推荐信、吉姆留下的名片、那些 X 光片复印件。他没有翻动它们，只是看着。指尖在抽屉边缘停了一瞬，然后他把它推了回去。

动作很轻。合上的声音在寂静中像某种宣判。

他走进卧室。

艾琳娜侧躺着，呼吸平稳。她的轮廓在黑暗中薄得像一张纸。他想起她今天悄悄藏起的那块染血的手帕——她以为他没看见。

他轻轻地坐下来，床垫微微下陷。

算了,还是去疗养院看看吧。

眼下，那是唯一的办法了。
