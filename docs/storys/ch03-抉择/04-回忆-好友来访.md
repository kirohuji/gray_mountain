# 回忆·好友来访

## ——早些日子，客厅——
(汤姆坐在客厅的沙发上，回忆起前段时间好友来拜访的情景。)

那天的阳光很充足。和现在截然不同.

好友吉姆将一张名片放在桌子上。

名片是厚实的象牙白纸张，边缘烫金。"亨利·韦斯特"——字体是旧式的衬线体，让人联想到上个世纪的墓碑。
下面一行小字：灰山疗养院 · 院长。

汤姆拿起名片，看了看。

艾琳娜自从搬来波士顿，身体状况就大不如前。起初他们看了很多医生，可得到的结果都是"水土不服"。

后来艾琳娜不愿再就医，说这太费钱了，她的病不是什么大问题。

汤姆隐隐感觉不是那样，为此焦躁不安。

吉姆：这位医生就是灰山疗养院的院长，亨利·韦斯特医生。

汤姆：我之前带艾琳娜看过很多医生。都说是水土不服。过敏。各种说法都有。

他从公文包里抽出一份剪报，放在名片旁边。那篇报道的标题是《灰山奇迹——结核病患者的最后希望》，署名是吉姆自己。

汤姆快速扫了一眼。

吉姆：我去年写过这篇报道。当时只是觉得是个有噱头的医学科普选题。但我写完之后留了心——一直在跟进那些人。

汤姆：……然后呢？

吉姆向前倾身，双手交握，指节因为用力而泛白。

吉姆：我查过。波士顿过去五年，有超过四十个病例——一模一样的症状。持续性咳嗽、体重下降、皮肤出疹、夜间盗汗。所有常规检查都查不出原因。

汤姆：……然后呢？

吉姆：然后他们都被送去了灰山疗养院。然后——好了。

他说"好了"这个词的方式，让汤姆很不舒服。

吉姆：韦斯特医生——他是目前全美最好的结核病专家。他在灰山建立疗养院已经二十年了。我调阅了他发表的所有论文，查看了所有他能公开的病历。数据不会骗人。

他从公文包里抽出几张 X 光片复印件，铺在汤姆面前。

黑白影像上，两片肺叶的轮廓明明暗暗。汤姆隐约能看到密密麻麻的白点。

汤姆把 X 光片举到灯下。

那些白色的斑点密密麻麻，像夜空中过度曝光的星辰。但有一个细节让你手一抖——

在右肺的位置，那几个白色斑点连起来，形成了一个轮廓。一个很小的、蜷缩着的轮廓。像一个婴儿的形状。

汤姆把片子扔回桌上。

吉姆：你看到了？

汤姆：……我不知道我看到了什么。

吉姆：我也不确定。但韦斯特医生也许知道。

汤姆：但是，这不可能。她从来不抽烟，也不在污染环境里。

吉姆：那些病例里，一半的人都不抽烟。

汤姆连连摇头，表示不相信。

吉姆欲言又止，最后叹了口气。

汤姆深呼吸，示意他继续。

吉姆：韦斯特医生的疗养院，建立在灰山半山腰。那里的海拔、空气质量、日照时长——都是经过科学测算的。

吉姆：他采用的是综合性治疗方案：山间新鲜空气、充足的日光照射、科学调配的休养与运动。

吉姆：听起来像是骗人的温泉度假村宣传册，对吗？

他苦笑了一下。

吉姆：我也是这么想的。直到我看到了那些病人的数据。韦斯特医生说大部分病人都痊愈了。

汤姆思考了许久，看着 X 光片。

吉姆：这名片你留着。用不用得上，以后再说。

汤姆：……

吉姆：我明白你的顾虑。但这是目前最好的选择。

汤姆: 我先去问下福特医生的意见。
