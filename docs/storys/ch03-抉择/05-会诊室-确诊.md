# 会诊室·确诊

## ——福特医生的会诊室——

汤姆来到了福特医生的会诊室。福特医生是艾琳娜的特别私人医生。艾琳娜的病情他是最清楚的。

会诊室不是医院那种冷冰冰的白，墙是暖灰色的石材，几盏黄铜壁灯投下温和的光。壁炉上方挂着一只标本鹿的头，玻璃眼珠在火光里一闪一闪。

查尔斯·福特医生从皮质扶手椅中站起来。他六十岁上下，脊背微驼，眼镜片很厚，看人时需要微微仰头。他说话不像吉姆提到的那位亨利医生那样斩钉截铁，声音平缓，像在斟酌每一个词的分量。

福特：卡特先生。请坐。

汤姆坐下。面前摊着一本厚重的文件夹。

福特沉默了一会儿，摘下眼镜擦了擦。这是汤姆见过的最不像在宣布坏消息的开场——但恰恰是这种沉默，让他心里一沉。

福特：您妻子的病，确实是肺结核。而且已经不是早期了。

汤姆摇头，手指攥紧桌沿。

汤姆：不，这不可能。她从来不抽烟，也不在污染环境里工作。

福特：肺结核的早期症状和普通感冒很像。

福特：请允许我反问一个问题——在您看来，肺结核是一种什么病？

汤姆愣了一下。

汤姆：……肺部感染。细菌造成的。

福特：对。但也不全对。

他站起身，走到书架前，抽出一本厚重的医学图册，翻开放在汤姆面前。

福特：肺，在传统医学中被视为人体最脆弱的器官。它直接与外界接触——每一口呼吸，都是在和这个世界进行交换。

福特：肺不像皮肤有层层屏障。它的屏障只有一层薄薄的黏膜。比一张纸还要薄。

他的手指在图册上划过肺泡的插图。

福特：肺结核是一种很特殊的细菌感染。它和普通的细菌感染不一样。

汤姆：什么东西？

福特没有直接回答。他放下图册，从抽屉里取出一份文件，推到汤姆面前。那是一封推荐信，抬头写着"灰山疗养院"。

福特：我治不了这个病。波士顿能治这个病的医生，不多。

福特：但我知道一个人——亨利·韦斯特医生。他在灰山上建了一座疗养院，专门收治这种病例。

汤姆低头看着那封信。纸张边角微微泛黄，像是提前准备好的、随时准备开给下一个绝望的人。

福特：韦斯特医生在灰山二十年，收治过两百多例。我不说大话——但数据摆在那里。

汤姆：……治愈率多少？

福特推了推眼镜。

福特：很高。

他说了"很高"，但没有说具体数字。汤姆注意到这一点。

福特：我认识韦斯特医生很多年了。他这个人——有些偏执，不太与人交际。但他对待病人的态度……我没有见过比他更认真的。

福特：您可以去看看。和他谈一谈。如果您觉得不妥，再做其他打算。

他说得很平静，不像推销，更像是在陈述一个他已经多次给过相同建议的事实。

汤姆：这疗养院……和普通的医院有什么不同？

福特：他们用山上新鲜的空气、日照、休养和运动来做基础治疗。另外——韦斯特医生有自己的配方。一种营养补充剂，据说是从山里的草本植物提取的。

汤姆：什么成分？

福特：他不知道是什么成分，也没有人知道。

他顿了顿。

福特：但那些病人——确实好起来了。

汤姆沉默了很久。窗外有马车的声响经过，然后又归于安静。

福特：决定权在您手里，卡特先生。但您妻子的病情——不宜等待太久。

他站起来，向汤姆伸出手。

福特：这封推荐信，您拿着。如果决定去，直接联系韦斯特医生就好。

汤姆接过推荐信，信纸在手里很轻，很薄。

汤姆：……谢谢你，福特医生。

福特：不客气。祝您妻子早日康复。

汤姆离开会诊室。
