# 灰山·上山与教堂

## ——灰山——

这天十分阴冷。

车子沿着山路盘旋而上。挡风玻璃外，灰白色的雾越来越浓，视野不断收缩，像是有什么东西正从四面八方围拢过来。

刚下过雨，路面泥泞，车轮碾过碎石发出细碎的声响。汤姆不得不放慢速度，身体前倾，紧盯着前方时隐时现的路面。

开了快两个小时，他才在半山腰看到那座教堂。

它几乎是隐形的，消失在灰白色的雾气中，像是被雾气吞没了一般。

石头砌成的外墙覆盖灰绿色的地衣，让汤姆想到慢性皮肤病人的模样。时间侵蚀的石墙坑坑洼洼，但孔洞却是光滑的。苔藓从里面长出来，细密的、泛白的，像死者的胡茬。

或许还有更贴切的说法，但汤姆想不起来。

他停下车，走近了一些，才看见原来那顶上是蒙灰的玻璃。

只有特定角度才能被察觉的玻璃。

那并不神圣，反而有诡异的荒芜感。汤姆犹豫了一下，还是推开了教堂的门。

"吱呀"一声，门被推开了。并没有他想象中沉重，倒像是无用的掩盖，在心理上阻止他进入。

教堂里有些昏暗，微弱的光透过玻璃，照亮上头画着的东西。

圣母玛利亚？

不，那只是个怀抱婴儿的女人。

汤姆从没见过如此诡异的画。

她的脸——如果还能被称之为脸，已经融化成背景。可唯独那轮廓还在，形成令人头皮发麻的错觉。

她好像正在笑。背后的透光让她被笼罩在阴影里。

可她微微上扬的，不属于圣母的唇角，就像是在怜悯汤姆。

？？？：您是迷路了吗。

汤姆被这沙哑的声音吓了一跳。

回过头，身披白袍的老人正站在门内侧的阴影中。

他颧骨高耸，眼窝深陷，每走一步都带着沉重的呼吸。

汤姆看着他走过来。

老人面无表情地看着他。

迈克尔：我是这里的神父，迈克尔·奥布莱恩。

汤姆：奥布莱恩教父，您好。我是来拜访疗养院的亨利医生的。顺路经过这里，想拜访一下。

迈克尔咳嗽了几声.

迈克尔：欢迎您，卡特先生。我在这住了有些年头了。这附近有个小村庄，附近的村民经常来这里做礼拜.疗养院的话离这里还有一段距离. 大概在这个方向,您顺着这条路一直走就能看到.

汤姆：谢谢您，教父。

汤姆离开教堂，沿着山路向疗养院开车过去。一路上偶尔能遇到几个村民，他们似乎对汤姆的到来并没有什么感到好奇,因为来疗养院的人最近越来越频繁了. 

倒是这附近有个村子,汤姆想的是下次来的时候可以去看看.
