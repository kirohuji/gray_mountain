# 哈丁医生

## ——波士顿，哈丁医生的诊室——

诊室铺着深绿色的丝绒。灯光昏暗。所有尖锐的边角都被圆润的木质家具取代。汤姆坐在皮质扶手椅里，膝盖上放着那本速写本。吉姆坐在他旁边。哈丁医生坐在对面，手里拿着莫恩的册子。他已经看了五分钟。

哈丁合上册子。

哈丁：这本册子——您是从哪里得到的。

汤姆：教堂。山脚的教堂。奥布莱恩神父。

哈丁点了点头。汤姆注意到他点头的方式——太快了。不是确认，是正在把什么东西归类。哈丁站起来，走到书架前。他的手指从一排排书脊上划过，停在一本厚重的旧笔记本上——封面没有标题，边角磨损，黑色皮革已经泛灰。

哈丁：伊莱沙·莫恩——是这家疗养院的初代建立者。1915年。他同时也是我的导师。我跟他学了两年精神病学，直到1920年——他回到了波士顿。被送回来的。不是我送回来的。他坚持要回来。

他把笔记本翻开。里面夹着几页手写的信纸。

哈丁：莫恩在1920年春天写了一封信给我。这封信——我保留了十六年，没有给任何人看过。

他把信纸抽出来，但没有直接递给汤姆。他读了一段。

哈丁："我在这些病人的肺部听诊中发现了一个无法归类的附加音。不是医学上已知的任何一种呼吸音。如果将这个频率从听诊器中转录——你会发现它有一个固定的节拍。每分钟六次。我测量了六十名病人。六十名病人，同一个节拍。偏差不超过零点三秒。这不可能。这不是人类生理学的可能范围。我测量了山体——"

他停了一下。

哈丁："——我测量了山体表面的微震。同一个节拍。每分钟六次。石灰岩在呼吸。我的病人不是在呼吸空气。他们是在和这座山进行气体交换。每一个肺泡都是一个微型接口。"

他放下信纸。诊室里很安静。吉姆的手指攥着扶手。

哈丁：我可以用医学解释他后来的状态。精神分裂。偏执型。伴有躯体妄想——他确信自己的气管里长出了石灰岩晶体。死因记录是异物堵塞气管——窒息。法医的鉴定是"死因自然，异物性质未明"——那是一颗完整的、成型的石灰岩晶体。从会厌软骨一直长到环状软骨，把气管完全堵死了。这不是隐喻。这是事实。

他摘下眼镜擦了擦。

哈丁：但我不认为您来我这里是为了听故事。吉姆告诉我您最近的情况——不睡觉，不吃东西，跟您妻子说话，而她已经去世三个月了。他把您画室里那些画跟我说了。您认为那些画不是您画的。您认为有什么东西——山——石灰岩——重新组装了您的画作。

他向前倾身，双手交握。

哈丁：卡特先生。我接下来要说的话是作为您的医生说的。您妻子的结核病——确实发生过。这所疗养院——确实治好了很多人。而在此之外发生的一切——您描述的山的呼吸，画的变化，石灰岩在生物组织中的生长——这些体验对您来说是完全真实的。我承认这一点。它们对您来说是真实的。您没有在说谎。您没有在编造。您正在经历一个极为真实的——精神事件。

他把莫恩的册子推回汤姆面前。

哈丁：我导师当年给我写那封信的时候，我相信他是诚实的。但他在经历一个精神事件的同时，也是一个正在向结核末期下滑的慢性病人。同样的症状——失眠，营养不良，组织缺氧——可以在大脑中产生极为逼真的体验。精神疾病——真正的、医学意义上的精神疾病——不是在制造假象。是在重新组织真实。

他停顿了一下。

哈丁：我的建议是住院观察。两周。如果两周后您的状态稳定了，吉姆说他想接您去乡下住一段时间。如果您不想去乡下，这里永远有床位。决定权在您手里。

汤姆低头看着速写本。封面上的那道白色细线还在——石灰岩粉尘自行排成的那道线。他翻开最后一页。石粉还在沉积。艾琳娜的轮廓已经被漫到了胸口。她的嘴还是微笑的弧度。她的喉咙正中，有一个灰白色的小结晶正在成形。

他合上本子，站起来。

汤姆：我跟你去精神病院。

吉姆长长地呼出一口气。哈丁点了点头，在病历上写字。

汤姆走到门口时停下了。他回头看着哈丁——看着他桌上那本莫恩的笔记本，那些发黄的信纸。然后他说了一句哈丁没有预料的话。

汤姆：他在信里有没有说那个附加音的频率——是在哪一个肺叶的位置记录到的。

哈丁的手指在桌面上停了半秒。然后他把信纸翻过来，扫了一眼最后一段。

哈丁：右肺上叶。肺尖。

汤姆低下头。

汤姆：艾琳娜的X光片。最早的那张——婴儿形状的斑点。也在右肺上叶。

没有人说话。

汤姆推开门，走进走廊。

*(治疗明天开始。)*
