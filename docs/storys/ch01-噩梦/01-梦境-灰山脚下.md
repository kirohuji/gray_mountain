# 灰山

## ——梦境：灰山脚下——

飘雪落在肩头，他首先感觉到的是冷。

（四周是无边无际的黑暗，他像是被塞进了一个没有尽头的虚空。唯有远处，隐约有什么东西。）

紧接着，冰凉的空气灌入口鼻，汤姆不由得弯腰咳嗽。嗓子像被砂纸打磨过，每一次干咳都带出铁锈味。他不记得自己之前在哪里，也不记得自己是怎么到这个地方的。脑子里像被掏空了一块，只剩下一种模糊的、没有源头的不安。

眼前的黑暗模糊地变亮，他看见自己站在茫茫大雪中，被灰色的庞然大物笼罩。

（那庞然大物立在极远的地方，却在视野中占据了半个天幕，压迫感丝毫没有因为距离而减弱。它不动。它甚至可能永远不会动。但汤姆盯着它的时候，总觉得它在看着自己——用某种没有眼睛的方式。）

不远处山峦叠层起伏，却并非常规那样——反而像是一头远古巨兽的脊背，一节节脊椎骨沉睡着隆起，仿佛从世界诞生之初就卧在这里。雪落在那些脊背上，像是皮肤上的霜。

他大张着嘴想要呼吸，可突然空气却怎么都进入不了肺部。肺在胸膛里徒劳地抽动，像搁浅的鱼。就好像被掐了脖子一样，喘不上气。

因缺氧而眼前发黑，边缘泛起老电视雪花的噪点。

然后，突然一片寂静。

不是逐渐寂静，而是像被吞掉般。雪落的声音没了，风声没了，连自己咳嗽的回音都消失了。整个世界像是被人摁下了静音键。太安静了，安静得不正常，安静得像死亡本身发出的声音。

莫名的、不知缘由的。

他感觉有什么东西在凝视他。

他汗毛竖了起来。他甚至能感觉到那视线的重量——沉甸甸地压在头顶、肩胛骨、后腰。他想回头，可脖子僵住了，像锈死的门轴。

那东西正悄然接近他。（从远处的黑暗移来，无声无息。每一步都踩在他心跳的间隙里。）在他身后、在他周围，宛若蜘蛛编网般束缚他。不，不是蜘蛛网，是更黏腻的东西。像是有什么潮湿的、巨大的东西正缓缓展开，一圈一圈地把他缠住，从脚踝到膝盖，从腰腹到胸口。他知道自己在收紧，却看不见那是什么。

咚咚，咚咚。他听见耳边的心跳声。

即将跳出胸膛的剧烈，让汤姆头皮发麻。他甚至能感觉到太阳穴在跳，眼球后面的血管在突突地撞。他下意识地按住胸口，浑身都在出汗。

然而当他想抬脚离开时，才惊觉有东西早已缠绕他的脚踝，将他死死固定在原地。他低头去看，雪地里什么都没有。可那种被抓住的感觉真实得可怕，像是有手指深深嵌进了骨头缝里。他开始挣扎，腿却像灌了铅，又像根本不是自己的。

什么都没有了。

他向下看但是什么都看不到，周围一片漆黑，只有自己的脚下有一片柔软的触感。

不是潮湿土壤，也并非坚硬的石灰岩，反倒像是——生物的、温热的血肉。鼓起、落下，然后再鼓起。像是什么东西在呼吸。又像是有什么东西埋在这雪地下面，活着，有温度，正在他掌心下沉睡。

.....!!!!

有什么声响！！！！

不是从耳朵里听见的。是从骨头里，从脊椎深处，从牙齿根部钻上来的。嗡嗡的，低沉的，像是什么巨大的东西在远距离发声。

那声音顺着他脚踝从下至上钻入他的骨髓，刻在他的骨头上阵阵发颤。

黑暗的眼前开始扭曲，恐惧如墨水旋转扩张，却成为他此刻唯一的实体。
