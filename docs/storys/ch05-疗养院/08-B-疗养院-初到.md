# [Version B] 疗养院·初到

## ——疗养院——

这座疗养院跟汤姆想的有所不同。

依山而建，因此大部分墙壁都是石头做的。他伸手去摸，刺骨的冰凉，让他又把手弹了回去。

山上空气清新，很快就让汤姆恢复平静。

他暂时忘记了，刚才在教堂里遭遇的一切。

院长已经在门口等待，见到汤姆的身影，他走上前迎接。

亨利：欢迎您，卡特先生。

汤姆：这里和我想的不太一样。

亨利：您指的是？

汤姆：我以为会更加……严肃。

亨利脸上冷漠的表情微微松动。

亨利：哈哈,实际上那样并不利于病人恢复，我们想要的是轻松自由的气氛。

说着，他转过身。

亨利：请跟我来，我带您参观一下。

疗养院整体由石灰岩打造，与山体是同一种石头，同一种灰白色调。

墙体与山体之间已经看不出缝隙，像是长在了一起，严丝合缝。

外墙刷漆成白色，给人一种宁静的氛围。

令汤姆印象最深刻的，是病房内巨大的窗户。

自穹顶延伸至墙壁中段，仿佛教堂透光的玻璃。暖阳从外面照射进来，汤姆整个人都沉浸于此。

然后他又来到阳台。

这里的地面有略微倾斜，韦斯特院长说是为了使雨雪更好滑落。

然而无可避免的，这里还是很湿滑，因此汤姆只在这里短暂地停留片刻就离开了。

亨利：卡特先生，您觉得如何？

汤姆深深地吸了一口气。

无比清新的空气，混杂着阳光的气味窜入鼻腔，奇迹般地抚平了他近些天的焦躁不安。

也许吉姆说的没错，这家疗养院真的能治好他的妻子。

之后亨利院长带着汤姆参观了疗养院的其他地方。

疗养院内部延续了外部的风格——灰白石材，高挑天花板，一丝不苟的整洁。

但有一处细节令你无法移开视线：病房内巨大的窗户。从穹顶延伸至墙壁中段，仿佛教堂透光的玻璃——和那教堂的窗户几乎一模一样的设计。只是这里的玻璃是透明的，暖阳从外面照射进来，将整间病房染成蜜色。

汤姆不知不觉又走进阳台。

病人们正在晒太阳。他们被护士推出来，或者自己走出来，躺在那些略显湿滑的躺椅上，小心翼翼地，防止自己摔倒。

他们脸色算不上平静，灰白的、蜡黄的、泛着不健康潮红的。

但都闭着眼睛，胸膛缓慢地起伏。

汤姆不由自主地注视着他们。

瘦弱的脊背在薄薄的病号服下凸起，一节一节清晰可见。

他们在呼吸。那起伏是平缓的，是有规律的，是活着的证据。

亨利院长：卡特先生，您觉得如何？

汤姆：这里很安静，很舒适。

亨利院长：因为我们希望病人在这里能够放松身心，恢复健康。

汤姆：这里的病人看起来都很安静。

亨利院长：没错,他们在这里接受治疗，恢复健康。

汤姆对着院长点头表示同意。

汤姆：那么接下来还请麻烦您了，韦斯特院长。

*

亨利院长带着汤姆从三楼沿着楼梯往下走。经过二楼走廊尽头时，汤姆停下了脚步。

那里有一扇门——不是病房的那种白色木门，是更厚重的铁门。门框上方的油漆剥落了一块，露出底下锈蚀的金属。门上没有编号，没有标签，只有一个插销，从外侧锁着。

汤姆：那里面是什么？

亨利院长的脚步顿了不到一秒。

亨利：噢噢, 那边是一个旧档案室。都是前几任院长的文件。我们会把资料都放在那里进行封存,已经很久没打开了。

他继续往前走，步伐比之前更快了一点。

汤姆跟上去。经过那扇门时，他的肩膀离门只有一掌的距离。没有风，门的边缘却发出了一声极细微的震颤——不是从外面传进去的，是从里面传出来的。

他转过头。门缝下面，逸出一丝几乎是透明的冷气，在这个季节不该这么凉。

*

他们来到一楼的大厅。墙上挂着一排裱好的黑白照片。院长们的肖像，按年份排列，最新的那一幅是韦斯特医生自己——白大褂，抿着嘴，目光直视镜头。

汤姆的视线掠过那些照片，然后停在最左边的那幅上。

照片上的人大约四十多岁。和韦斯特医生一样穿着白大褂，但眼神不同——不是严肃，是紧张。不是对着镜头紧张，是瞳孔本身就在扩张，像被什么持续惊吓着。嘴角的形状似乎是后来修过，微微上扬，但颧骨的阴影没有被修掉，把微笑变成了某种生理性的痉挛。

照片下方的铜牌上刻着：伊莱沙·莫恩，1915–1920。

汤姆感觉到好奇,不由自主地问道

汤姆：亨利院长,请问一下,这位是？

亨利院长从身后走来。他看了一眼照片，脸上的肌肉没有动，但汤姆注意到他的手指在大腿侧面轻轻攥了一下。

亨利：这位首任院长。旧档案室里的东西大部分是他的。

亨利院长的目光从照片上移开。

亨利：后来他去世以后,这里的管理移交到了我手上。卡特先生，时间不早了，请允许我送您到门口。

汤姆走出疗养院时回头看了一眼。一楼大厅的灯光还亮着，那些肖像照在玻璃框里反着光。莫恩的那张被吊灯的余光照亮了半边——那半张脸看起来不像是在笑。像是在说。

*

他们搬来疗养院的间隔并不久。

下定决心后，汤姆便回去告诉了艾琳娜。

艾琳娜并不反对，实际上她再不忍心拒绝丈夫的期待，因此默许了搬去疗养院的决定。

汤姆说到：艾琳娜，你一定会好起来的!

像是在对她做承诺般，汤姆握着她的手说。

然而短暂呼吸的间隙，他又觉得自己嗅到一丝不安的气息。

汤姆马上安慰自己，没事的，不要胡思乱想。
