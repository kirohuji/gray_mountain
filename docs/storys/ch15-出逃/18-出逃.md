# 出逃

## ——精神病院到灰山——

他走的时候没有人发现。

凌晨三点。走廊里只有应急灯投下暗绿色的光。汤姆穿着病号服，外面套了一件从洗衣房顺手拿的旧外套。脚上是病房的软底拖鞋。他身上带了三样东西：莫恩的遗稿，速写本。口袋里那颗石灰岩晶体——已经在震颤。他不需要指南针。他知道方向。

走出大门的一刻，灰白色的细尘落在他脸上。不是只在山上飘的——现在整个波士顿都在飘。他抬头看，街灯的光束里全部是那些东西，一层一层旋转着往下渗透。

他沿着查尔斯河往西走。路边的建筑越来越少，路面从沥青变成了碎石。天亮时他走到了郊区边缘。一个女人在自家院子的草坪上扫地——不是落叶，不是灰尘，是石灰岩粉尘。她抬头看了他一眼，没有问为什么一个穿病号服的男人在凌晨步行，只是点了点头，然后继续扫地。

中午他在一座废弃的加油站里找到了一个背包。旧报纸，一瓶没喝过的水。他把速写本塞进背包。晶体在口袋里震得更快了。他往前走。他不知道距离有多远。他只知道那个节拍在变强。不是他靠近了山，是山靠近了他。森林，然后坡地，然后碎石路。雾从坡上涌下来，已经分不出是空气还是粉尘。他踩上去，脚底下的路面是硬的——软底拖鞋不足以隔绝温度，路面是凉的，山基的石头把冷气从地底抽上来。他踩的不是路面。是山的下颌。

走了两天一夜。他在溪边停了一次——喝了两口水，把水倒在自己的喉咙上，试图让那个硬点安静下来。结节没有安静。结节在振动。不是疼痛——是饥饿。他的喉咙想被填满。被石灰岩粉尘填满。

第三天，他看到教堂的尖顶从雾中浮现。教堂比他记忆中更灰了。外墙上的地衣已经不再是绿色，而是被石灰粉尘覆盖成白色。那扇门开着。奥布莱恩站在门口，黑袍，白发。他看到汤姆走过来——穿着病号服、旧外套、软底拖鞋，走进山门前——什么都没有说。他让到一边，把门推开，就像他等了很多年。

教堂里没有其他人。圣安妮的脸还在融化。但融化的方向变了——不是融入背景，是正在从背景里长出来。从画布上的那层颜料中，有极其细微的白色纹理正在往外延伸。不是颜料剥落——是画布在结晶。圣安妮的轮廓比上次更清晰了。不是画家补了笔。是石灰岩粉尘在画布上接续了那些没完成的线条。再过一百年，她的脸会长全的。不是人类的面容——是人理解了山以后能承受的面容。

汤姆在长椅上坐了一根烟的时间。奥布莱恩给了他一条厚裤子和一双皮靴。一壶茶。他没有喝——他把茶倒在喉咙里。结节安静了一秒。然后又开始。更快了。他站起来——直接上山。

山路被石灰岩粉尘覆成灰白色。路面不再是碎石——全是石灰岩粉尘。踩下去不是硬的了，是软的，像踩在更深的什么东西上。树木被压弯，有些倒在了路面上——不是枯死的。是石化的。松针变成灰白色，硬而且脆；树干上爬着石灰岩脉的网，在树皮下隐隐透出灰白色的光。空气不是空气了——全是粉尘，是山呼出的气。他的呼吸变得越来越平缓，不是因为他不累，是因为他的肺正在被一种更慢、更深的频率替代。每分钟六次。他没有窒息。他的肺部正在吸收粉尘——不是被呛到，不是被堵住，是被充满。像缺了一辈子的东西终于补上了。

疗养院在他前方浮现。

建筑已经面目全非。外墙被石灰岩粉尘完全覆盖，不再是白色的墙——是被石化了，是整栋楼正在从建筑变成地质构造。阳台上的躺椅被压在石粉下面，只剩下一排轮廓。大窗户的玻璃变成了不透明的灰白色——矿化。窗格上爬着石笋的银线。只有两扇窗户例外——南向病房的那扇大窗户和北翼的那扇铁门。两处的玻璃都还是透明的，向外射出微弱的光。不是灯火——是石灰岩晶体的冷光。像深海的磷火，像骨头贴着皮肤时的那种白。

他穿过不再有门的大厅，走上楼梯。墙壁上挂着的肖像——韦斯特医生的还在，莫恩的不在了。那个空着的镜框里现在填满了石灰岩晶体，正在按照照片的尺寸往外延展。晶体正在重新塑造那张脸——他不用等。他知道那张脸长什么样。就是莫恩。莫恩从来没有离开过。他一直在这里。他把自己反锁在地下档案室，只是向北翼走了那一步。他的肺不需要空气，只需要那个频率。十六年。他用了十六年完成了最后的改建。现在他在照片里。在墙壁里。在汤姆喉咙里那个正在变大的节拍里。

三楼的走廊尽头，贝茨太太的房门开着。椅子上没有人。但椅子上有一层厚厚的石灰岩粉末——不是灰尘堆积的空轮廓。粉末上躺着一双拖鞋，一双毛线手套，一件褪色的开襟毛衣。毛衣是空的——但上面的纽扣还在原位，袖口还保持着手腕穿进去的形状。没有尸体，没有挣扎。只有那些衣物搁在粉末上，被自身重量压出衣褶，像身体只是突然蒸发了。石灰岩粉尘在毛衣表面继续沉积，绕过纽扣——那不是无差别覆盖。它认得每一颗塑料纽扣的边缘，每一根毛线的起止，把它们当作衣服，而不是当作她。

汤姆站在那扇门前，站了很久。

然后他转身，向南向病房走去。

艾琳娜的房间门开着。里面没有床了——床被石灰岩晶体托举在半空，不是坠毁，不是在破坏中悬浮——是在改建。每一根晶体都在垂直向上增长，从地板到床腿，从床腿到床梁，从床梁到床垫——全部被矿脉接管。床头柜上放着一枝薰衣草，被石灰岩粉尘完整包裹，连花萼都还在。干枯的紫色在灰白色的水晶里隐约透出。是他的妻子枕头上的那股甜。

床是空的。但被子掀开着。被单上有那个微凹的人形——和四个月前一模一样，没有被新雪盖掉。只是人形现在是灰白色的，全部用细晶矿了一层。矿层的厚度不是均匀的——腿的位置比较浅，胸口最深。最深的地方，晶体的排布不是无机的，不是随机的，是顺着肺泡的解剖弧度走的。

他跪在床边。

速写本从他手中滑落，翻到最后一页。艾琳娜的轮廓已经被石灰岩粉尘完全覆盖——没有消失，没有模糊。是完成了。每一粒石粉都定位在她身体的正确位置，骨骼、肌肉、头发的纹路——不是绘画。是复制。是她的第二具身体。是用山的物质重建的她。不是记忆。是备份。

口袋里那两颗结成一体的晶体——从她的气管，从他的喉咙——在共振中发出一声极轻极脆的裂音。不是裂开了。是合上了。中间的桥已经完全消失。它们不再需要连接——它们已经是同一颗。

病房的窗外，山顶裂缝中伸出的白色枝杈已经编织成一整片网络，从峰顶垂落至山腰，穿过疗养院的每一扇窗户。每一根枝杈都是石灰岩的远程延伸——是山的支气管，是连接无数肺部的通道。这些枝杈现在同时进入了他的胸腔——不是从外部穿刺，不是刺入皮肤。是从里面接上的。是从喉咙里的那个结节内部向外生长，与山伸下来的那根连成了一体。他终于可以呼吸了。不是他的呼吸——是山的。从灰山之巅，从裂缝，顺着那根枝杈，进入他喉咙里那个早已建好的接口，进入他的右肺上叶，再进入他不记得哪一刻已经被改建完毕的肺泡。每一颗肺泡现在都像莫恩的册子里最后那张图——微小的晶洞，内壁长满方解石的棱面。山的气体通过这条路进入他，他自己呼出的气体通过同一条路回到山体深处。他是它的一颗肺泡。是它的气体交换界面。

*(他开始理解了。)*
