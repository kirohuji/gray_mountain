# 滞留

## ——疗养院，艾琳娜死后第一周——

他不肯走。

吉姆从波士顿赶来接他——开了两个小时的车，碎石路上溅起的泥点干了又湿。他站在疗养院门口，看着汤姆坐在阳台上那把艾琳娜曾经躺过的椅子上，怀里抱着速写本。

吉姆：汤姆，该回去了。

汤姆没有回答。他看着远处山脊线，嘴唇微微动着。吉姆把一只手放在他的肩膀上，汤姆的身体僵了一瞬，然后——他没有转头，只是把那只手从肩上拿下来，

那本速写本被他翻得起了毛边。他每天翻。每天看。每天会发现新的线条——昨天没有的，前天就有了的。

玛格丽特护士端着药盘经过阳台，看了他一眼，什么都没说。她已经不再尝试跟他讲话了——第一天她试着给他送饭，他接过去，放在艾琳娜曾经坐过的空椅子旁边。饭凉了。他一口没吃。第二天她把饭放在椅子上。第三天她放弃了。贝茨太太让人转告他一句话："她还在。只是不在这个房间里。"

汤姆信了。

他在椅子上睡着了。梦里，他又站在灰山脚下。雪没过脚踝，但没有冷的感觉。脚下的地面在呼吸——鼓起、落下，鼓起、落下。和前几次不一样的细节：山顶裂缝不再是只有雪。从裂缝中伸出了白色的枝杈——分叉的、细密的，从山顶一直延伸到山腰，再延伸到山脚。不是树枝。和莫恩册子里画的一模一样的结构。肺的枝杈。山的裂缝在向外吐这些东西，一根根新的支气管正在往空气里蔓延。它们没有碰到他——在他的头顶一米处，像被什么东西托着。然后他低头。从他自己的胸腔里，从肋骨之间的缝隙里，同样的枝杈正在往外探出。白色的，细小的。他的，还是山的分支。两边的支气管在中点会合。

他醒了。速写本的封面上多了一道白色的细线。不是炭笔。是石灰岩粉尘，从窗外的空气中落在纸面上，在他睡着的时候自行排成了那道线。他顺着线去看——这道线在封面上向前延伸，最后消失在本子的装订缝隙里。他翻开那一页——线穿过了三页纸，每一页的石灰岩粉尘都以同样的走向向前延伸，然后在第四页——越过所有线之后的那页空白上——停了下来。最后一粒微尘停在那里。

像句号。像等待。

第五天，吉姆把他拉上了车。汤姆没有反抗。他只是回头看了一眼疗养院——三栋石灰岩建筑在雾中一动不动，阳台上的躺椅翻倒了一半。贝茨太太病房的窗户还亮着。那扇铁门还锁着。

他摸到口袋里的那颗晶体。还在。另一颗更小的——他自己的那颗——也在。两颗沙在口袋里互相摩擦，发出极细微的声音。不是沙粒碰撞的声音。是铃。是在某个极远、极深的地方，有什么东西在共鸣。

*(车发动了。下山。)*
