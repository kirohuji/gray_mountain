## 叙事结构

- **空间推进**：诊室（封闭/被审视）→ 返回公寓（空旷）→ 卧室（空）→ 画室（异常）→ 客厅（崩塌）
- **情感弧线**：被诊断的屈辱 → 急于回家找艾琳娜 → 找不到的焦虑 → 面对异常的恐惧 → 服药后的坠落
- **节奏控制**：01-02 缓慢（诊室的静止时间）→ 03 加速（匆忙寻找）→ 04 急转（画室异常）→ 05 崩塌

## 核心意象与母题

### 缺席
- 艾琳娜不在卧室——"床上只有一个人的凹陷"
- 梳妆台落了一层薄薄的灰
- 她的不在场比在场更有存在感

### 画
- 速写本上的雪地——不是汤姆画的
- 脚印在往纸边移动
- 画纸落下灰白色粉末
- 这是贯穿全章的核心意象：画不再是静态的记录，而是活的

### 药
- 白色小瓶——标签上写着"每晚一片"
- 药片是灰白色的，粗糙的，在呼吸
- 味道是铁的腥和石灰的涩
- 药不是药——是入口的东西
