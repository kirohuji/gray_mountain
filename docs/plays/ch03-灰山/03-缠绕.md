# 03：缠绕

> 莫名的、不知缘由的。你感觉有什么东西在凝视你。
>
> 你汗毛竖了起来。你甚至能感觉到那视线的重量——沉甸甸地压在头顶、肩胛骨、后腰。你想回头，可脖子僵住了，像锈死的门轴。
>
> 那东西正悄然接近你。从远处的黑暗移来，无声无息。每一步都踩在你心跳的间隙里。在你身后、在你周围，宛若蜘蛛编网般束缚你。不，不是蜘蛛网，是更黏腻的东西。像是有什么潮湿的、巨大的东西正缓缓展开，一圈一圈地把你缠住，从脚踝到膝盖，从腰腹到胸口。你知道自己在收紧，却看不见那是什么。
>
> 咚咚，咚咚。你听见耳边的心跳声。
>
> 即将跳出胸膛的剧烈，让你头皮发麻。你甚至能感觉到太阳穴在跳，眼球后面的血管在突突地撞。你下意识地按住胸口，浑身都在出汗。
>
> 然而当你想抬脚离开时，才惊觉有东西早已缠绕你的脚踝，将你死死固定在原地。你低头去看，雪地里什么都没有。可那种被抓住的感觉真实得可怕，像是有手指深深嵌进了骨头缝里。你开始挣扎，腿却像灌了铅，又像根本不是自己的。
>
> 什么都没有了。
>
> 你向下看但是什么都看不到，周围一片漆黑，只有自己的脚下有一片柔软的触感。
>
> 不是潮湿土壤，也并非坚硬的石灰岩，反倒像是——生物的、温热的血肉。鼓起、落下，然后再鼓起。像是什么东西在呼吸。又像是有什么东西埋在这雪地下面，活着，有温度，正在你掌心下沉睡。
