## 叙事结构

- **空间的推進**：从外部（公寓入口）向内推进，最终在客厅收束。玩家穿过走廊依次进入浴室、厨房、画室、客厅——每次进入都是一层更深的自我暴露。走廊是连接所有空间的血管。
- **情感弧线**：归来 → 观察 → 隐约不安 → 细节积累 → 无法忽略的裂缝 → 崩潰（电话铃响）→ 重逢（真假未明）。
- **時間軸**：整个章节发生在从疗养院回到家中的第一个傍晚。物理时间是压缩的，但叙事时间通过记忆碎片和物品细节展开——每一件物品都在追问：你不在的時候，这里发生了什么？
- **节奏控制**：场景 01-03 是渐强的细节积累（粉末、干燥的牙刷、温毛巾），04（走廊）以一种"安静的异化"在过渡空间中制造不安——熟悉的空间开始变得不对，05-07 是裂缝的扩大，08 是情感的爆发与悬置。

## 核心意象与母题

### 灰白色粉末

贯穿全章的视觉母题。出现在：

- 行李袋侧面（01）
- 她鞋底的边缘（01）
- 锅底（02）
- 调色盘（05）
- 阳台栏杆/外套袖口（07）

> 质地：细腻、滑腻、像石粉。来源不明。不是灰尘。

**叙事功能**：粉末是一种"痕迹"——不是某个人留下的，而是某种 *过程* 留下的。它暗示着一种缓慢的、不可逆的物质转化——石灰化、钙化、石化。每次出现都让读者离真相更近一步，但永远不够近。

### 镜子与延迟

- 玄关穿衣镜（01）：镜中的自己慢了半拍。
- 浴室镜子（03）：未直接描写但始终在场——在浴室这个空间里，镜子是不可避免的凝视装置。

> 镜子不只是反射——它开始 *滞后*。暗示汤姆的自我认知正在与他的身体脱节。

### 卧室的门（缺席的在场）

- 核心意象。门不是"锁了"——是"被顶着"。
- 卧室门位于客厅——走廊的尽头，这个家最深处。玩家走到客厅才会发现它。
- 艾琳娜从未在 01-07 中出现，但她的存在渗透在每一个细节中：她的鞋、她的牙刷、她的杯子、她画中的轮廓。
- 门不是为她关的——门是为了让她从里面打开。这是一个倒置的悬念：不是"她是否在里面"，而是"她什么时候出来"。

### 石子/振动

- 第一次出现：口袋里的石子以每分钟六次的频率振动（08）。
- 节奏与心跳一致。

> 心跳频率 = 六次每分钟？这在生理上是异常的（正常心率 60-100 次/分钟），暗示汤姆的身体状态已经偏离了正常范围——或者他被某种外力同步了。

### 雪/灰白细尘

- 收束场景（08）：窗外开始飘雪——但不是雪，是灰白色细尘。
- 只有他的窗户在落。对面公寓什么都没有。
- 融合了两个母题：粉末（物质转化）+ 雪（寂静、覆盖、终结）。

## 关键叙事技巧

- **第一人称不可靠叙述**：汤姆的视角就是读者的全部信息。但汤姆刚从疗养院回来，他的感知能力被暗示为不可靠的——他可能看到了真相，也可能正在解离。
- **舞台指示的克制**：舞台指示精确但不冷感。环境描写承载了大部分情感重量。
- **对话的稀缺**：全章仅有的对话来自吉姆（寥寥数句）和艾琳娜（收束场景）。其余均为内心独白或物品描述。这种沉默本身就是一种叙事——隔离、孤独、无法言说。
- **物品叙事**：每个可交互物品都是一个微型故事。物品不解释，只呈现。读者和汤姆一起拼图。

## 衔接与伏笔

| 伏笔 | 出现场景 | 指向 |
|------|---------|------|
| 灰白色粉末的来源 | 01、02、05、07 | 后续章节的"石化/钙化"主题 |
| 滤芯被替换（太干净了） | 02 | 有人在维护这个家——但不是以正常的方式 |
| 速写本上的灰山地图（内脏图） | 05 | 灰山不只是地理位置——它是一个有机体 |
| "不是疾病。是设计。" | 06 | 指向更大的力量在操控事件 |
| 药瓶上消失的字 | 06 | 现实的边界开始模糊——书写可以自行出现和消失 |
| 艾琳娜的"真实" | 08 | 全篇核心谜题——后续章节逐步揭示 |

## 叙事风格提示

- 简洁、冷静的旁观者语调——不煽情，不解释
- 舞台指示精确但不冷感
- 对话极少但分量重——每句话都不可跳过
- 环境细节承载情感重量
- 维持一种"一切正常"的表面，让裂缝自己显现
