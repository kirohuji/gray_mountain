# ch01 归途 · 章节总览

## 场景总览

| 编号 | 场景 | 叙事功能 | 氛围基调 |
|------|------|---------|---------|
| 01 | 归途 | 开场：吉姆送汤姆回家，留下他独自一人 | 寂静、疲惫、疏离 |
| 02 | 沉睡 | 疲惫压倒一切，他在沙发上睡去 | 下沉、遗忘、时间的断裂 |
| 03 | 电话 | 被电话铃惊醒，穿过昏暗走廊接听 | 刺耳、遥远、低频嗡鸣 |
| 04 | 重逢 | 艾琳娜坐在卧室床边——她回来了 | 温暖与恐惧交织、真假莫辨 |
| 05 | 门铃 | 吉姆在门外，说有预约，被拉走 | 仓促、被推着走、回头 |

## 出场人物

| 角色 | 出场场景 | 备注 |
|------|---------|------|
| 汤姆（主角） | 全部 | 第一人称视角，全程在场 |
| 吉姆 | 01、05 | 朋友——始终站在门口的人 |
| 艾琳娜 | 04 | 仅在卧室场景中出现——"回来了"的她 |
| 哈丁医生 | 电话中被提及（03） | 未出场 |

## 叙事结构

- **空间推进**：从公共空间（玄关/客厅）向内推进到私密空间（走廊/卧室），再被拉回玄关（门铃）
- **情感弧线**：疲惫 → 沉入睡眠 → 惊醒 → 难以置信的重逢 → 被拉走（未完成的告别）
- **节奏控制**：开场缓慢（独处+沉睡），中段急转（电话铃），高潮（重逢），戛然而止（门铃/被拉走）

## 核心意象与母题

### 门
- 吉姆站在门口不进来（01）
- 汤姆推开卧室的门（04）
- 公寓的门开着一道缝，他被拉走时回头（05）
- 每一道门都在隔离——他从未真正"进入"任何状态

### 声音的断裂
- 门锁咔嗒声（01）
- 电话铃刺穿寂静（03）
- 吉姆的声音被嗡鸣覆盖（03）
- 艾琳娜的声音太过正常（04）
- 门铃截断了一切（05）

### 时间的不连续
- "连续几天没有真正睡过觉"（01）
- "你忘了跟她说什么"（05）
- "像是昨天。像是上周。像是刚才。"（03）
