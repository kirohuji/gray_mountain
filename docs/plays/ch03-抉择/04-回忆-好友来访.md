# 回忆·好友来访

## ——早些日子，客厅——

好友将一张名片放在桌子上。

汤姆拿起来看，上面写着"亨利·韦斯特"，职业是一家疗养院的院长，下面写着详细地址。

吉姆：你的妻子——艾琳娜，近两年一直在咳嗽生病吧？

艾琳娜自从搬来波士顿，身体状况就大不如前。起初他们看了很多医生，可得到的结果都是"水土不服"。

后来艾琳娜不愿再就医，说这太费钱了，她的病不是什么大问题。

汤姆隐隐感觉不是那样，为此焦躁不安。仔细想来，那个奇怪的梦也是在艾琳娜生病后开始的。

吉姆：韦斯特医生……哦，我曾经帮他刊登过疗养院的新闻，算是朋友。这不重要，重要的是——他是个优秀的医生。

吉姆：我向他描述过艾琳娜的病情，这位优秀的结核病专家认为，艾琳娜也许是肺结核。

汤姆：不，这不可能。

像是要说服自己，汤姆连连摇头。
吉姆欲言又止，最后叹了口气。

吉姆：老兄，我只是推荐你去。
吉姆：韦斯特医生有家出色的疗养院，若是你有需要，我会尽力帮忙。

汤姆：……
