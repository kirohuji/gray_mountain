# 002 - 修复：图片居中 + 字体 + Ren'Py 8.5.2 兼容

## 改动概要

修复游戏运行时的三个问题：背景图不铺满屏幕、字体未配置、Ren'Py 8.5.2 API 兼容。

## 文件变动

| 文件 | 操作 | 说明 |
|------|------|------|
| `game/script.rpy` | 修改 | 图片定义加 `fit="cover"` 使其铺满屏幕 |
| `game/scripts/ch01_return.rpy` | 修改 | 删除 `renpy.start_predict`（已在 `image` 定义中自动加载） |
| `game/gui.rpy` | 修改 | 三个字体变量改为 `fonts/AaShiGeMingXinPian-2.ttf` |

## 详细说明

### 图片铺满 (`game/script.rpy`)
```renpy
# 修改前
image bg apartment_foyer = "images/scene1.png"
# 修改后
image bg apartment_foyer = Transform("images/scene1.png", fit="cover")
```
- `fit="cover"` 保持宽高比缩放，覆盖整个屏幕（可能裁切边缘）

### 删除无效 API (`game/scripts/ch01_return.rpy`)
- `renpy.start_predict()` 在 Ren'Py 8.5.2 中不存在且不必要
- 图片已在 `script.rpy` 的 `image` 语句中定义，由引擎自动管理

### 字体 (`game/gui.rpy`)
- `gui.text_font` → `fonts/AaShiGeMingXinPian-2.ttf`
- `gui.name_text_font` → `fonts/AaShiGeMingXinPian-2.ttf`
- `gui.interface_text_font` → `fonts/AaShiGeMingXinPian-2.ttf`
